# QA 14 — the folder browser, improved (ADR 0009, 222–225)

Asked to optimize and enhance the in-app folder browser and to test choosing a new folder end to end. The product owner chose faster and safer navigation, orientation (Places, breadcrumbs, open marks), keyboard and filter, and a New folder button. Every scenario names its test. Kernel tests use the testkit and a temporary tree; `test/web/` mounts the app in happy-dom against a fake API; `test/e2e/` drives Chromium against a real kvman.

## Happy path

- **QA14-H1 `kernel.folder.create` makes a folder and answers its real path.** *Given* a folder `root`, *when* `kernel.folder.create { path: root, name: 'new project' }` runs, *then* the folder exists inside `root`, the answer is `{ path: <real root>/new project }`, and `kernel.folder.list` of `root` now lists it. (`packages/testkit/test/folders/folder-create.test.ts`)
- **QA14-H2 A new folder can be made, entered, and opened as a workspace, end to end.** *Given* a real kvman and a temporary tree, *when* the person opens "Open a folder…", goes to the tree, presses "New folder", types a name, and confirms, *then* the folder exists on disk, the dialog is inside it (empty), and "Open this folder" opens it: the picker's current workspace is the new folder, `kernel.workspace.list` has it with its real path, and the Chat page asks what to build in it. (`extensions/kvwebui/test/e2e/folder-browser.test.ts`)
- **QA14-H3 Quick clicks never show an older answer.** *Given* a slow answer for folder A and a quick one for folder B, *when* A is clicked and then B before A answers, *then* when A's answer arrives late the dialog still shows B. (`extensions/kvwebui/test/web/folder-navigation.test.ts`)
- **QA14-H4 A folder that is opening shows a loading state, and the last folder stays.** *Given* a slow answer, *then* while it is pending the list has `aria-busy="true"` and the spinner shows, the old folders are still listed, and both go when it arrives. (`extensions/kvwebui/test/web/folder-navigation.test.ts`)
- **QA14-H5 Folders already seen show at once and are read again.** *Given* the person went from `/a` into `/a/b` and presses Up, *then* `/a` shows before its answer arrives and the query runs again; the new answer replaces it when it differs. (`extensions/kvwebui/test/web/folder-navigation.test.ts`)
- **QA14-H6 Back returns to the folder shown before.** *Given* `/a` then `/a/b` then `/a/b/c`, *then* Back shows `/a/b`, then `/a`, and is off at the first. (`extensions/kvwebui/test/web/folder-navigation.test.ts`)
- **QA14-H7 Breadcrumbs jump to any parent.** *Given* `/home/me/projects/todo`, *then* the segments `/`, `home`, `me`, `projects`, `todo` are shown, a click on `me` lists `/home/me`, and for `C:\Users\me` the segments are `C:\`, `Users`, `me`. (`extensions/kvwebui/test/web/folder-places.test.ts`, `extensions/kvwebui/test/unit/folder-path.test.ts`)
- **QA14-H8 Places lists Home and the open workspaces.** *Given* Home and two open workspaces, *then* Places shows Home and the two folders; a click goes to that folder; the place of the folder shown is marked. (`extensions/kvwebui/test/web/folder-places.test.ts`)
- **QA14-H9 A folder that is already a workspace is marked.** *Given* `/work/project` is an open workspace, *then* its entry carries the "Open" mark and the others do not. (`extensions/kvwebui/test/web/folder-places.test.ts`)
- **QA14-H10 The filter narrows the list.** *Given* folders `alpha`, `Beta`, `alphabet`, *when* `ALPH` is typed, *then* `alpha` and `alphabet` stay, and `zzz` shows "No folder matches"; Escape clears it and shows all. (`extensions/kvwebui/test/web/folder-keyboard.test.ts`)
- **QA14-H11 The keyboard walks the list.** *Given* the dialog just opened, *then* the filter box has focus; ArrowDown highlights the first folder, again the second; ArrowUp goes back; Enter enters the highlighted folder; Backspace in the empty filter goes up; Enter with none highlighted opens the folder shown. (`extensions/kvwebui/test/web/folder-keyboard.test.ts`)
- **QA14-H12 New folder creates it and enters it.** *When* "New folder" is pressed, a name typed, and Enter or Create pressed, *then* `kernel.folder.create { path: <shown>, name }` runs, the browser enters the new folder, and the listing of the parent is read again when the person comes back up. (`extensions/kvwebui/test/web/folder-create.test.ts`)
- **QA14-H13 In a real browser the keyboard and breadcrumbs work.** *Given* a real kvman, *then* typing in the filter, arrow keys, Enter, Backspace, and a breadcrumb click move through a temporary tree as above. (`extensions/kvwebui/test/e2e/folder-browser.test.ts`)

## Edge cases

- **QA14-E1 Bad names are refused.** *Given* `''`, `'   '`, `'a/b'`, `'a\b'`, `'.'`, `'..'`, a NUL, and 256 characters, *then* each fails `VALIDATION_FAILED` saying why and nothing is made; 255 characters works. (`packages/testkit/test/folders/folder-create.test.ts`)
- **QA14-E2 An existing name, a bad parent, and an unwritable parent fail.** *Given* a name that exists (as a folder or a file), a relative, missing, or file `path`, and a parent that can't be written, *then* each fails `VALIDATION_FAILED` with its reason. (`packages/testkit/test/folders/folder-create.test.ts`)
- **QA14-E3 The names are checked per platform.** *Given* the Windows rules, *then* `a:b`, `a*`, `con`, `NUL.txt`, `LPT1`, `x.`, and `x ` fail and `console`, `a.b`, and `Ünï` work; on the other systems the Windows-only ones work. (`packages/kernel/test/folders/folder-name.test.ts`)
- **QA14-E4 It makes one level only, and the name is trimmed.** *Then* `'  tidy  '` makes `tidy`, and nothing is made above `path`. (`packages/testkit/test/folders/folder-create.test.ts`)
- **QA14-E5 The listing is the same with parallel checks.** *Given* symlinks to folders, files, and nothing, *then* the list is as in QA13-E3, in name order. (`packages/testkit/test/folders/folder-list.test.ts`)
- **QA14-E6 Making a folder forgets its parent's listing.** *Given* `/a` was listed and cached, *when* a folder is made in it, *then* going back to `/a` shows it. (`extensions/kvwebui/test/web/folder-create.test.ts`)
- **QA14-E7 A refused name shows why and keeps the row.** *Given* the command fails `VALIDATION_FAILED`, *then* the reason shows under the name, the name stays typed, the browser stays where it was, and the Create button works again. (`extensions/kvwebui/test/web/folder-create.test.ts`, `extensions/kvwebui/test/e2e/folder-browser.test.ts`)
- **QA14-E8 The cache holds at most 50 folders and keys on the hidden setting.** *Given* 51 folders visited, *then* the first is read fresh; with Show hidden on, a folder seen without it is read, not shown from the cache. (`extensions/kvwebui/test/web/folder-navigation.test.ts`)
- **QA14-E9 The filter clears when the folder changes, and Escape closes only when it is empty.** (`extensions/kvwebui/test/web/folder-keyboard.test.ts`)
- **QA14-E10 Every new text is in both languages.** *Then* `en` and `ar` have the same keys. (`extensions/kvwebui/test/locales.test.ts`)
- **QA14-E11 The dialog fits a narrow window, in either language.** *Given* windows 360 and 600 wide, in English and Arabic, *then* the dialog and its parts have no horizontal scroll and the buttons are in view. (`extensions/kvwebui/test/e2e/folder-browser.test.ts`)
- **QA14-E12 Windows paths are read for the segments and the places.** (`extensions/kvwebui/test/unit/folder-path.test.ts`)
- **QA14-E13 A path being typed is never replaced.** *Given* the first listing is slow, *when* a path is typed and then the listing arrives, *then* the path field keeps what was typed and Enter goes there; the field follows the folder shown again after the person goes somewhere (by Enter, a click, Up, Back, a segment, or a place). (`extensions/kvwebui/test/web/folder-navigation.test.ts`)
