# QA 42 — kvbuilder edits the running preset, saves a new one, and knows what is installed (ADR 0030)

Asked: "I want to edit kvman builder to teach him that the user able to edit current preset or create a brand new preset. Also it should have all required knowledge about all installed extensions and kvman patterns and convetions".

Every earlier scenario that counts three built-in guides is read with four, `conventions` first.

## Happy path

### The kernel

- **QA42-H1 `kernel.preset.settings.set` sets one value in the preset file.** *Given* a home preset with `settings: { "a.one": 1 }` and the registered key `a.two` (a number), *when* `kernel.preset.settings.set { key: 'a.two', value: 2 }` runs, *then* it answers `{ file, restartRequired: true }` with the preset's file, the file's `settings` are `{ "a.one": 1, "a.two": 2 }`, its `name` and `extensions` are unchanged, and `kernel.preset.get` shows the same. `packages/kernel/test/preset-edit/settings-set.test.ts`
- **QA42-H2 Setting a key again replaces its value.** *When* `a.one` is set to `5`, *then* the file has `"a.one": 5` once. `packages/kernel/test/preset-edit/settings-set.test.ts`
- **QA42-H3 A preset with no `settings` gains them.** *Given* a preset file without `settings`, *when* a value is set, *then* the file has `settings` with that one key, after `extensions`. `packages/kernel/test/preset-edit/settings-set.test.ts`
- **QA42-H4 The first edit of the bundled preset copies it.** *Given* the bundled preset running, *when* a value is set, *then* `<home>/presets/<name>.json` holds the bundled preset with the value, and `kernel.preset.get` has `origin: 'home'` and that `file`. `packages/kernel/test/preset-edit/settings-set.test.ts`
- **QA42-H5 An edit of a value keeps the backup.** *When* a value is set after a good start, *then* `<file>.good` holds the preset as it was running; a second edit leaves it unchanged. `packages/kernel/test/preset-edit/settings-set.test.ts`
- **QA42-H6 The value applies at the next start, not before.** *Given* a preset-only key, *when* it is set and `kernel.settings.list` is read, *then* its value is still the running one; after a restart it is the new one, with `source: 'preset'`. `packages/kernel/test/preset-edit/settings-restart.test.ts`
- **QA42-H7 `kernel.preset.settings.reset` removes one value.** *Given* `settings: { "a.one": 1, "a.two": 2 }` where `a.two` has a default, *when* `reset { key: 'a.two' }` runs, *then* it answers `{ file, restartRequired: true }` and the file's `settings` are `{ "a.one": 1 }`. `packages/kernel/test/preset-edit/settings-reset.test.ts`
- **QA42-H8 `kernel.presets.save` writes a preset by its name.** *When* `kernel.presets.save { preset: { name: 'notes-app', extensions: { '@kvman/kvai': 'bundled', notes: 'path:/abs/notes' }, settings: { 'kvwebui.home': 'notes.list' } } }` runs, *then* it answers `{ file: '<home>/presets/notes-app.json' }`, that file parses to the same preset, and `kernel.preset.get` is unchanged. `packages/kernel/test/preset-edit/presets-save.test.ts`
- **QA42-H9 `replace: true` overwrites a saved preset.** *Given* `notes-app` saved, *when* it is saved again with `replace: true` and other settings, *then* the file holds the new preset. `packages/kernel/test/preset-edit/presets-save.test.ts`
- **QA42-H10 The CLI finds a saved preset by its name.** *Given* a preset saved as `second`, *then* the CLI's preset lookup of `second` on that home answers that preset, with `origin: 'home'` and the saved file. `packages/cli/test/preset-lookup.test.ts`

### kvbuilder's connector

- **QA42-H11 `kvman preset-set` and `preset-reset` wrap the kernel's commands.** *When* `kvbuilder.app.preset.settings.set { key: 'kvwebui.title', value: 'notes.app.title' }` runs, *then* it answers the kernel's `{ file, restartRequired: true }` and `kvbuilder.app.preset.get` shows the value; `kvbuilder.app.preset.settings.reset { key }` of a key with a default removes it. `extensions/kvbuilder/test/app-preset.test.ts`
- **QA42-H12 `kvman preset-save` saves the workspace's preset file.** *Given* `apps/notes-app.json` in the workspace, written by `preset new` with `name: 'notes-app'` and the entry `"notes": "path:../notes"`, *when* `kvbuilder.app.preset.save { file: 'apps/notes-app.json' }` runs, *then* it answers `{ file: '<home>/presets/notes-app.json', name: 'notes-app' }`, and that file has `"notes": "path:<workspace>/notes"` and the other entries unchanged. `extensions/kvbuilder/test/app-preset.test.ts`
- **QA42-H13 The three commands are in the `kvman` connector and ask.** *Then* `kvcoder.connector.list` has `kvman` with the commands `preset-set`, `preset-reset`, and `preset-save`, each with `asks: true`, each naming its `kvbuilder.app.preset.*` command, which is public; and the descriptions of `kvman` and `preset` name saving a preset. `extensions/kvbuilder/test/registration.test.ts`
- **QA42-H14 A call of one asks the person first.** *When* the model calls `kvman preset-set` in a chat that ran `/build-kvman`, *then* the turn waits on an approval, and the preset file is unchanged until it is allowed. `extensions/kvbuilder/test/app-asks.test.ts`

### What the chat knows

- **QA42-H15 `/build-kvman` sets the index.** *When* `kvbuilder.build.start` runs, *then* `kvcoder.section.list { sessionId }` has `{ id: 'installed', title: 'Installed in this app', order: 21, owner: '@kvman/kvbuilder', global: false, sessionId }` after `guide`, and the chat's prompt contains the index's text. `extensions/kvbuilder/test/build-start.test.ts`
- **QA42-H16 The index lists what runs.** *Given* the `coder` extensions and a `todo` extension with a setting, a public command, a public query, and no docs, *then* the text starts `Preset: <name> (<origin>)`; has one block for each extension, by name; the block of `@kvman/kvwebui` is `- @kvman/kvwebui (kvwebui), bundled, <version>`, its `settings:` line with its keys by name, its `public queries:` line, and `pages: components (<title>), views (<title>)`; the `todo` block has `settings:`, `public commands:`, `public queries:`, and `pages: none`; no private command or query is named; and the last line is "This is what ran when /build-kvman was typed. `kvman extensions-list` and `docs list` are current." `extensions/kvbuilder/test/installed-index.test.ts`
- **QA42-H17 A second `/build-kvman` renews the index.** *Given* building on in a chat, *when* the command runs again, *then* there is one `installed` section and no second note. `extensions/kvbuilder/test/build-start.test.ts`
- **QA42-H18 `conventions` is a built-in guide.** *Then* `listBuiltInGuides()` answers `conventions`, `i18n`, `presets`, `sdk`, in that order; `readBuiltInGuide('conventions')` has the title "Conventions"; and its text names each of: the `<namespace>.<segment>` name rule with the verbs a command and a query end in, `<namespace>/UPPER_SNAKE` error codes, `execAsync` and `ctx.schedule` for long work, `ctx.registerHandler`, `scopes`, `en` and `ar`, `<namespace>.ui.get`, and `<namespace>.docs.list`. `packages/testkit/test/docs/built-in-guides.test.ts`
- **QA42-H19 `docs list` and `docs get` have it.** *Then* `kvbuilder.guides.list` starts with the four built-in guides, and `kvbuilder.guides.get { topic: 'conventions' }` answers its Markdown. `extensions/kvbuilder/test/docs.test.ts`
- **QA42-H20 The scaffold copies four guides.** *When* `kvman-new` writes a project, *then* its `docs/` has `conventions.md`, `i18n.md`, `presets.md`, and `sdk.md`. `packages/testkit/test/scaffold/kvman-new.test.ts`
- **QA42-H21 The guide teaches presets.** *Then* the guide's text has, between the rules and the method: that the section "Installed in this app" is what runs here; `preset-set` and `preset-reset` for a value of this app, naming its name and home page; the new-preset steps in the order `preset new`, `preset check`, `preview start`, `ask confirm`, `preset-save`; and the line `kvman --preset <name>`. `extensions/kvbuilder/test/guide.test.ts`
- **QA42-H22 The guide says to read first.** *Then* it tells the agent to read `conventions` before writing or changing an extension or a preset, and an extension's pages before building on it. `extensions/kvbuilder/test/guide.test.ts`
- **QA42-H23 The agent changes the app's home page from a chat.** *Given* the `coder` extensions and a chat that ran `/build-kvman`, *when* the model calls `kvman preset-set { key: 'kvwebui.home', value: 'kvwebui.extensions' }` and the person allows it, *then* the call's result has `restartRequired: true`, and `kernel.preset.get` has that value. `extensions/kvbuilder/test/e2e/presets.test.ts`
- **QA42-H24 The agent saves a new preset, and kvman starts it by name.** *Given* a preset file written with `preset new`, *when* the model calls `kvman preset-save` and the person allows it, *then* the result names `<home>/presets/<name>.json`; and a kvman started on that home with `--preset <name>` answers `kernel.health.get` with that preset's name. `extensions/kvbuilder/test/e2e/presets.test.ts`

## Edge cases

- **QA42-E1 A registered key's value is checked.** *Then* `kernel.preset.settings.set` of a number key to `'x'` fails `VALIDATION_FAILED`, and the file and its backup are as they were. `packages/kernel/test/preset-edit/settings-set.test.ts`
- **QA42-E2 An unknown key is refused while every extension of the preset is loaded.** *Then* `set { key: 'nobody.key', value: 1 }` fails `VALIDATION_FAILED` and writes nothing. `packages/kernel/test/preset-edit/settings-set.test.ts`
- **QA42-E3 An unknown key is taken while an extension waits for its first start.** *Given* an extension installed in this run and not loaded, *when* `set { key: 'later.mode', value: 'on' }` runs, *then* it succeeds and the file has the value. `packages/kernel/test/preset-edit/settings-set.test.ts`
- **QA42-E4 A preset-only key is set, and a key in every scope too.** *Then* a key with `scopes: []` and a key with the default scopes are both written. `packages/kernel/test/preset-edit/settings-set.test.ts`
- **QA42-E5 `reset` of a key the preset doesn't have fails `NOT_FOUND`.** *Then* the file is unchanged. `packages/kernel/test/preset-edit/settings-reset.test.ts`
- **QA42-E6 `reset` of a required key is refused.** *Given* a key registered without a default, *then* `reset` fails `VALIDATION_FAILED` and the file keeps it. `packages/kernel/test/preset-edit/settings-reset.test.ts`
- **QA42-E7 Removing the last value leaves a valid preset.** *When* the only key is reset, *then* the file parses as a preset, and a restart starts. `packages/kernel/test/preset-edit/settings-reset.test.ts`
- **QA42-E8 Edits run one after the other.** *When* a `set`, an `install`, and another `set` are sent at once, *then* the file has all three changes. `packages/kernel/test/preset-edit/concurrent.test.ts`
- **QA42-E9 A start that fails after a value edit is undone.** *Given* a value that makes the start fail `VALIDATION_FAILED` (an unchecked key no extension registers), *when* kvman restarts, *then* the file is restored from its backup and the next start's `kernel.health.get` has `rolledBack`. `packages/kernel/test/preset-edit/settings-restart.test.ts`
- **QA42-E10 An existing preset isn't overwritten without `replace`.** *Then* a second `kernel.presets.save` of the same name fails `VALIDATION_FAILED`, with `replace: false` too, and the file is the first one. `packages/kernel/test/preset-edit/presets-save.test.ts`
- **QA42-E11 The running preset's name is refused.** *Then* `kernel.presets.save` with the running preset's name fails `VALIDATION_FAILED`, with `replace: true` too, for a bundled and for a home preset, and writes nothing. `packages/kernel/test/preset-edit/presets-save.test.ts`
- **QA42-E12 A `path:` source must be absolute.** *Then* `path:./notes` and `path:notes` fail `VALIDATION_FAILED`. `packages/kernel/test/preset-edit/presets-save.test.ts`
- **QA42-E13 The preset must have a preset's shape.** *Then* a missing `name`, an unknown top-level key, a bad source, and the names `Notes`, `notes_app`, `../x`, `a/b`, and `x.json` each fail `VALIDATION_FAILED` and write nothing. `packages/kernel/test/preset-edit/presets-save.test.ts`
- **QA42-E14 Saving installs and trusts nothing.** *When* a preset with an `npm:` and a `path:` extension is saved, *then* nothing is installed, no trust is recorded, and the running extensions are unchanged. `packages/kernel/test/preset-edit/presets-save.test.ts`
- **QA42-E15 The kernel's Problems pass through the connector.** *Then* `kvbuilder.app.preset.settings.set` of an invalid value fails `VALIDATION_FAILED`, `.reset` of a missing key `NOT_FOUND`, and `kvbuilder.app.preset.save` of a name that exists `VALIDATION_FAILED` until `replace: true`. `extensions/kvbuilder/test/app-preset.test.ts`
- **QA42-E16 `preset-save` reads only a preset inside the workspace.** *Then* `file: '../out.json'` fails `VALIDATION_FAILED`, a file that isn't there `NOT_FOUND`, a file that isn't JSON and one that isn't a preset `VALIDATION_FAILED`, and nothing is saved. `extensions/kvbuilder/test/app-preset.test.ts`
- **QA42-E17 An absolute `path:` entry and the other sources are kept.** *Then* a file with `path:/abs/x`, `bundled`, and `npm:1.2.3` entries is saved with them unchanged. `extensions/kvbuilder/test/app-preset.test.ts`
- **QA42-E18 An extension whose docs fail is listed with no pages.** *Given* an extension whose `docs.list` throws, *then* its block has `pages: none`, and the other blocks are whole. `extensions/kvbuilder/test/installed-index.test.ts`
- **QA42-E19 An index over the cap is cut at a whole block.** *Given* enough extensions that the text passes 16 KB, *then* the text is at most 16 KB, ends with the last line followed by ` <n> more extensions aren't listed here.` with the right count, and has no half block. `extensions/kvbuilder/test/installed-index.test.ts`
- **QA42-E20 A line with nothing is left out.** *Given* an extension with no setting and no public command or query, *then* its block is its first line and `pages: none`. `extensions/kvbuilder/test/installed-index.test.ts`
- **QA42-E21 A session kvcoder refuses gets no index.** *Then* `kvbuilder.build.start` of an unknown session fails `kvcoder/SESSION_NOT_FOUND`, and no section is left. `extensions/kvbuilder/test/build-start.test.ts`
- **QA42-E22 The guide still fits a section, and keeps its rules.** *Then* the guide's text is at most 16 KB, still has the questions, the rules, and the method in order, and the words it tells the agent to keep from the person still include presets. `extensions/kvbuilder/test/guide.test.ts`
- **QA42-E23 `kvman-docs` lists four guides with no kvman running.** *Then* `kvman-docs list` prints `conventions`, `i18n`, `presets`, and `sdk`. `packages/testkit/test/e2e/kvman-docs-not-running.test.ts`
