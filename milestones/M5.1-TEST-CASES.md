# M5.1 — kvvideo set up: test cases

Read: `16` §16.1 to §16.4, §16.9; `08` §8.4; `06` §6.3, §6.6; ADR 0107.

The layers: kvvideo in a test kernel with kvai, kvwebui, and kvcoder (`extensions/kvvideo/test/support/kvvideo-kernel.ts`); stand-in `ffmpeg`, `ffprobe`, and `piper` programs, small Node scripts that the `kvvideo.programs.*` settings name, which answer as the scenario needs; the readiness parts as unit tests with stand-in runners and browsers; and the check with the installed Chrome in the e2e project.

## Happy path

### M5.1-H1 — kvcoder has the video connector, off until /video, and the slash command
- **Given** kvvideo in a test kernel
- **When** the kernel has started, and again after a restart
- **Then** `kvcoder.connector.list` has `video`, owned by `@kvman/kvvideo`, `optIn`, with `check` → `kvvideo.setup.get` and `fonts` → `kvvideo.font.list`, each a query, with an example; `kvcoder.slash.list` has `video` → `kvvideo.video.start` with its two keys
- Test: `extensions/kvvideo/test/registration.test.ts`

### M5.1-H2 — /video turns the connector and the guide on in one chat, with one note
- **Given** two chats
- **When** `kvvideo.video.start` runs twice for the first
- **Then** the first chat's prompt lists `video` with its description and has the section "Making videos" from `docs/guide.md`; the second chat's has neither; the note `kvvideo.video.started` is added once
- Test: `extensions/kvvideo/test/registration.test.ts`

### M5.1-H3 — kvvideo's extension page has three configuration cards
- **Given** kvvideo loaded
- **When** `kvvideo.ui.get` is called
- **Then** it has no pages, nav, panels, or status items, and its configuration is the cards Narration (`service`, `voice`, `model`), Recording (`browser`), and Programs (`ffmpeg`, `ffprobe`, `piper`), each a `setting` row, with titles in `en` and `ar`
- Test: `extensions/kvvideo/test/configuration.test.ts`

### M5.1-H4 — the settings and their defaults
- **Given** kvvideo loaded
- **When** `kernel.settings.list` is read
- **Then** the seven keys have their defaults and scopes (§16.2), and each has a title and description in `en` and `ar`
- Test: `extensions/kvvideo/test/configuration.test.ts`

### M5.1-H5 — check is ready when nothing is missing
- **Given** stand-in programs that answer a version, every encoder and the `subtitles` filter, and a Piper help that exits 0; the service `piper` with a voice
- **When** `kvvideo.setup.get` runs (the browser part through a stand-in launcher)
- **Then** `ffmpeg` is `{ ready: true, version: '7.1', missing: [] }` and `narration` `{ service: 'piper', ready: true, missing: null }`
- Test: `extensions/kvvideo/test/setup.test.ts`

### M5.1-H6 — the installed browser is found
- **Given** the installed Chrome
- **When** `video check` runs in the e2e project
- **Then** `browser` is `{ ready: true, channel: 'chrome' }`
- Test: `extensions/kvvideo/test/e2e/check.test.ts`

### M5.1-H7 — fonts lists the five bundled fonts, each in the package with its licence
- **Given** kvvideo loaded
- **When** `video fonts {}` runs through `runConnector`
- **Then** it answers `Amiri`, `IBM Plex Sans Arabic`, `Lato`, `Poppins`, `Tajawal` by name, the three Arabic ones with `['arabic', 'latin']` and the others `['latin']`; each font's file and its OFL licence exist in `fonts/`, and the package's `files` include `fonts`
- Test: `extensions/kvvideo/test/fonts.test.ts`

### M5.1-H8 — kvvideo is bundled in the coder preset
- **Given** the `kvman` package
- **When** its preset and dependencies are read
- **Then** `coder.json` has `@kvman/kvvideo: bundled`, and `@kvman/kvvideo` is a dependency of `kvman`
- Test: `extensions/kvvideo/test/bundled.test.ts`

## Edge cases

### M5.1-E1 — ffmpeg that can't start
- **Given** `kvvideo.programs.ffmpeg` naming a program that doesn't exist
- **When** `check` runs
- **Then** `ffmpeg.missing` is `['ffmpeg', 'libx264', 'aac', 'libmp3lame', 'subtitles']`, `version` is `null`, `ready` false; `check` doesn't fail
- Test: `extensions/kvvideo/test/setup.test.ts`

### M5.1-E2 — ffmpeg without libass or an encoder; ffprobe missing
- **Given** a stand-in ffmpeg without `libmp3lame` and `subtitles`, and no ffprobe
- **When** `check` runs
- **Then** `missing` is `['ffprobe', 'libmp3lame', 'subtitles']`, in that order
- Test: `extensions/kvvideo/test/setup.test.ts`

### M5.1-E3 — a program that doesn't answer in time
- **Given** a program that never exits, with a 200 ms limit
- **When** the readiness run waits for it
- **Then** it counts as missing, and its tree is killed
- Test: `extensions/kvvideo/test/unit/run-program.test.ts`

### M5.1-E4 — the browser channels tried
- **Given** a stand-in launcher where no channel starts, then where only `msedge` does
- **When** the browser part runs with `auto`, with `chrome`, and with `msedge`
- **Then** `auto` tries `chrome` then `msedge`, and is `{ ready: false, channel: null }`, then `{ ready: true, channel: 'msedge' }`; `chrome` tries only `chrome`; a started browser is closed
- Test: `extensions/kvvideo/test/unit/browser-readiness.test.ts`

### M5.1-E5 — what narration is missing, first only
- **Given** in turn: no service; ElevenLabs without its key; OpenAI without its key; Piper whose help fails; Piper without a voice; ElevenLabs with its key
- **When** the narration part runs
- **Then** `missing` is `kvvideo.narration.service`, `elevenlabs.apiKey`, `openai.apiKey`, `piper`, `kvvideo.narration.voice`, then `null` with `ready: true`; no service is called
- Test: `extensions/kvvideo/test/unit/narration-readiness.test.ts`, `extensions/kvvideo/test/setup.test.ts`

### M5.1-E6 — invalid setting values
- **Given** kvvideo loaded
- **When** the person sets `kvvideo.narration.service` to `azure`, `kvvideo.browser` to `firefox`, and `kvvideo.programs.ffmpeg` in a workspace
- **Then** each fails `VALIDATION_FAILED`
- Test: `extensions/kvvideo/test/configuration.test.ts`

### M5.1-E7 — the tree kill per OS
- **Given** a pid
- **When** the kill is planned on `linux`, `darwin`, and `win32`
- **Then** Linux and macOS kill the group (`-pid`, `SIGKILL`); Windows runs `taskkill /PID <pid> /T /F`
- Test: `extensions/kvvideo/test/unit/kill-tree.test.ts`

### M5.1-E8 — a chat without /video has no video connector
- **Given** a chat where `/video` didn't run
- **When** the model calls `video check`
- **Then** the call answers kvcoder's "There is no connector video." error
- Test: `extensions/kvvideo/test/registration.test.ts`

### M5.1-E9 — every error code and text in both languages
- **Given** kvvideo's catalogs
- **When** they are read
- **Then** `en` and `ar` have the same keys, including `kvvideo.errors.<CODE>` for the seven codes, the slash texts, and the note
- Test: `extensions/kvvideo/test/unit/catalog.test.ts`
