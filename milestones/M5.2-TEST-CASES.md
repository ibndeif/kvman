# M5.2 — Recording a page: test cases

Read: `16` §16.3, §16.5; ADR 0107, 18, 19, and 25.

The layers: the address rules, kvman's own port from `kvman.lock`, the step schema, and the output paths as unit tests; `record` through `runConnector` in the test kernel for what fails before a browser starts; the frame writer and ffmpeg's arguments as unit tests; and `record` end to end with the installed Chrome against a local test page (`extensions/kvvideo/test/support/test-page.ts`), in the e2e project, with a stand-in ffmpeg that counts the JPEG frames it reads and writes them as JSON, and once with the ffmpeg on the PATH (`real-ffmpeg.test.ts`).

## Happy path

### M5.2-H1 — a local page is recorded with every kind of step
- **Given** a local page with a link to a second page, a text field, a button that shows "Saved", a long list, and a box that appears after 300 ms
- **When** `record` runs with `click`, `type`, `press`, `hover`, `scroll` (down then up), `wait`, `waitFor`, and `goto`, at 640 × 360, to `videos/demo/01.mp4`
- **Then** ffmpeg got JPEG frames of 640 × 360 on stdin and the encoder's arguments, about 30 a second of `durationMs`, and its output is placed at the file; the page shows what the steps did (the typed text, "Saved"); the answer's `steps` have each `do` in order with rising `atMs`, the first at least 500, and `durationMs` is past the last `atMs` by at least 1000
- Test: `extensions/kvvideo/test/e2e/record.test.ts`

### M5.2-H2 — the default size, and the parent folders created
- **Given** a local page
- **When** `record` runs with no steps and no size, to `a/b/c.mp4`
- **Then** the folders are made, and the frames and the encoder's size are 1280 × 720
- Test: `extensions/kvvideo/test/e2e/record.test.ts`

### M5.2-H3 — the cursor is drawn
- **Given** the cursor script in a page
- **When** the mouse moves and is pressed
- **Then** a dot follows the mouse, and a press adds a ring at the dot
- Test: `extensions/kvvideo/test/e2e/record.test.ts`

### M5.2-H4 — replace writes over an existing file
- **Given** an existing `clip.mp4`
- **When** `record` runs to it with `replace: true`
- **Then** it holds the new recording
- Test: `extensions/kvvideo/test/e2e/record.test.ts`

### M5.2-H5 — a real recording
- **Given** the ffmpeg on the PATH
- **When** a page with a button is recorded at 640 × 360 with a click and a `wait` of 1000 ms
- **Then** ffprobe reads an H.264 video of 640 × 360 at 30 frames a second, without sound, whose length is `durationMs` within 200 ms
- Test: `extensions/kvvideo/test/e2e/real-ffmpeg.test.ts`

### M5.2-H6 — a steady frame rate from changing frames
- **Given** frames at 0, 100, and 450 ms from the start
- **When** the writer finishes at 1000 ms
- **Then** it wrote 30 copies: the first frame for slots 0 to 2, the second for 3 to 13, the third for 14 to 29; a recording with one frame writes it at least once
- Test: `extensions/kvvideo/test/unit/frame-writer.test.ts`

### M5.2-H7 — ffmpeg's arguments
- **Given** a size of 640 × 360
- **When** the encoder's arguments are made
- **Then** they read JPEGs from stdin at 30 a second, scale and pad to 640 × 360 in `yuv420p`, encode with `libx264 -preset veryfast -crf 18`, without sound, with `+faststart`
- Test: `extensions/kvvideo/test/unit/encoder-args.test.ts`

## Edge cases

### M5.2-E1 — addresses that aren't this computer's
- **Given** the address rules
- **When** they check `https://example.com`, `http://192.168.1.5:3000`, `ftp://localhost/`, `http://user:pass@localhost:3000`, `file:///etc/hosts`, and `http://localhost.evil.com`
- **Then** each fails `VALIDATION_FAILED`; `http://localhost:5173`, `https://127.0.0.1/`, and `http://[::1]:8080/a` pass
- Test: `extensions/kvvideo/test/unit/address.test.ts`

### M5.2-E2 — kvman's own address
- **Given** kvman's port 3737, from `<KVMAN_HOME>/kvman.lock`
- **When** `url` or a `goto` is `http://127.0.0.1:3737/` or `http://localhost:3737/x`
- **Then** it fails `VALIDATION_FAILED` before a browser starts; another port passes; with no `KVMAN_HOME`, no lock, or a lock without a port, no port is kvman's
- Test: `extensions/kvvideo/test/unit/address.test.ts`, `extensions/kvvideo/test/unit/own-port.test.ts`, `extensions/kvvideo/test/record-input.test.ts`

### M5.2-E3 — the page's requests to kvman's own address are aborted
- **Given** a kvman lock naming a local server's port, and a page that fetches from that server when it loads
- **When** the page is recorded
- **Then** the server gets no request, and the recording is placed; a request to that port on another name of this computer (`0.0.0.0`, `127.0.0.2`, `[::ffff:127.0.0.1]`, `LOCALHOST.`, `app.localhost`) counts as kvman's own too
- Test: `extensions/kvvideo/test/e2e/record.test.ts`, `extensions/kvvideo/test/unit/address.test.ts`

### M5.2-E4 — a target that doesn't appear
- **Given** a page without `#missing`
- **When** step 2 clicks `#missing`
- **Then** the call fails `kvvideo/STEP_FAILED { step: 2, reason }`, `reason` one line; no file is written and the temporary folder is gone
- Test: `extensions/kvvideo/test/e2e/record.test.ts`

### M5.2-E5 — a page that doesn't load
- **Given** a local port nothing listens on
- **When** `record` opens it
- **Then** it fails `kvvideo/STEP_FAILED { step: 0, reason }`; nothing is written
- Test: `extensions/kvvideo/test/e2e/record.test.ts`

### M5.2-E6 — the output rules
- **Given** an existing `clip.mp4`
- **When** `record` writes to it without `replace`, to `clip.webm`, to `../outside.mp4`, and to a link that points outside the workspace
- **Then** each fails `VALIDATION_FAILED` before a browser starts; `CLIP.MP4` passes the extension check
- Test: `extensions/kvvideo/test/record-input.test.ts`, `extensions/kvvideo/test/unit/workspace-paths.test.ts`

### M5.2-E7 — step limits
- **Given** the step schema
- **When** it reads 201 steps, a `wait` of 60 001 ms, a `scroll` of 20 001 pixels, a `type` of 2001 characters, an empty `target`, an unknown `do`, and an unknown key
- **Then** each fails `VALIDATION_FAILED`; a size under 320, over 1920, or odd fails too
- Test: `extensions/kvvideo/test/unit/steps.test.ts`

### M5.2-E8 — no browser
- **Given** a launcher where no channel starts
- **When** `record` starts its browser with `auto`
- **Then** it fails `kvvideo/BROWSER_MISSING { channels: ['chrome', 'msedge'] }`
- Test: `extensions/kvvideo/test/unit/browser-start.test.ts`

### M5.2-E9 — cancel closes the browser and ffmpeg
- **Given** a recording waiting 60 s
- **When** its job is cancelled
- **Then** the call ends `CANCELLED`, the browser and ffmpeg are stopped, and nothing is written
- Test: `extensions/kvvideo/test/e2e/record.test.ts`

### M5.2-E11 — ffmpeg fails or is missing
- **Given** a stand-in ffmpeg that exits 1 with "Unknown encoder 'libx264'", then an ffmpeg that can't start
- **When** a page is recorded
- **Then** the first fails `kvvideo/RENDER_FAILED { reason }` with that line, the second `kvvideo/PROGRAM_MISSING`; nothing is written
- Test: `extensions/kvvideo/test/e2e/record.test.ts`

### M5.2-E10 — the connector has record
- **Given** kvvideo loaded
- **When** the connector list is read
- **Then** `video` has `record` → `kvvideo.clip.record`, a command, with an example
- Test: `extensions/kvvideo/test/record-input.test.ts`
