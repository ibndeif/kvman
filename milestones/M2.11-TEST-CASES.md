# M2.11 — UI registry and localization (kernel): test cases

Read:

- `08` §8.6 (the UI registry), §8.16 (localization: the kernel parts), `02` §2.10 (context and `locale`).
- The parts they cite:
  - `08` §8.3 (frame slots), §8.4 (order, ids, hiding, inactive items), §8.5 (the `Text` fields), §8.17 (presets and visibility);
  - `03` §3.3 (admission step 2), §3.8 (the `kernel.ui.*` and `kernel.user.preferences.*` rows);
  - `04` §4.1 (`user_preferences`);
  - `05` §5.3 (`registerTranslations`, `registerSettingsSection`), §5.4 (`ctx.locale`, `ctx.i18n.t`, `ctx.problem`);
  - `06` §6.3 (the Text rule);
  - `07` §7.3–§7.4 (preset `labels`, `translations`, and where a preset is checked);
  - `12` §12.2 (the `/ui` routes, status codes);
  - `13` §13.1 (`Problem.params`), §13.2 (`VALIDATION_FAILED`, `NOT_FOUND`, `PRESET_REQUIRED`, `PRESET_INVALID`, `WORKSPACE_INVALID`, `CALLER_NOT_ALLOWED`, `EXT_MANIFEST_INVALID`).
- ADRs 0011, 0013, 0015, 0054, 0099, 0123, 0124, 0129, 0145, 0149, 0156–0158, and 0159–0161.

Earlier tests that M2.11 changes:

- **The runtime and daemon harnesses** stop passing `defaultLocale`: the locale comes from the saved preference (ADR 0161).
- **M1.3-H1** compares the whole M0.3 fixture, `translations` included: the pdf example registers its catalogs.
- **M2.10-E1** registers config along with `registerSettingsSection`, which now needs it (ADR 0160).
- **The M0.3 fixture** `pdf-manifest.json`: its `z.action()` props gain `format: 'kvman-text'` on their nested `Text` fields.
- **M2.1-E5, M2.1-E19, M2.1-E20, M2.7-E31, M2.10-H6** expect the literal-text warning at `meta.title` of their fixtures.
- **M2.10-E20** registers catalogs for its `$t.card.title`; **M2.10-E1** and **M2.10-E12** register config with their settings sections.
- **M2.1-E27** and **M2.8-E48** no longer expect `kernel.validate { catalog }` to be refused (M2.11-E50).

Not in M2.11:

- The shell's `t()`, the fallback rendering, `<html lang dir>`, and formatting: M3.1.
- The testkit's `asUser({ locale })` and its catalog checks: M2.13. Tests here set the language with `kernel.user.preferences.set`.
- `muted` in the preferences and everything about notifications: M2.12.
- Literal text as an error for builder-generated extensions: the builder (`11`).

Terms:

- "**Person**" is `user:local`, an administrator.
- "**Kit**" is the M2.10 fixture `@acme/kit`: page `kit.home` on `/kit`, slot `kit.tray` (accepts `panel`), entity `kit.item`, renderer target `kit.entry`, public composite `kit.card`. Its text is literal.
- "**Board**" is `@acme/board` 1.0.0 (namespace `board`). Its `meta.title` is `$t.meta.title`. It registers:
  - translations with default `en` and catalogs `en` and `ar`, holding every key it uses; `count` is `{count, plural, one {# card} other {# cards}}` in `en` and has all six Arabic forms in `ar`;
  - config with scope `both` (field `columns`, label `$t.settings.columns`), and a settings section whose view is a text node `$t.settings.intro`;
  - pages `board.home` on `/board` (view: the private composite `board.frame`, whose view uses the private composite `board.chip`) and `board.card` on `/board/:cardId`;
  - nav group `board.group` (order 100);
  - nav items `board.nav-home` (page `board.home`, group `board.group`, order 200) and `board.nav-top` (page `board.home`, no group, order 300);
  - toolbar items `board.find` (`frame.topbar.end`, order 50), `board.add` (`frame.topbar.end`, order 100), and `board.menu` (`frame.topbar.start`);
  - status items `board.count` (side `start`) and `board.sync` (no side);
  - panels `board.tip` in `frame.overlay` (view: a `board.chip` node) and `board.side` in `kit.tray`;
  - the action `board.pin` on `kit.item`;
  - renderers `board.row` for `kit.entry` and `board.pdf` for `mime:application/pdf`.
- "**Board 2**" is Board 2.0.0 with one more toolbar item, `board.share` (`frame.topbar.end`).
- "**Lingo**" is `@acme/lingo` (namespace `lingo`), installed sandboxed. It registers:
  - translations with default `en`:
    - `en`: `greeting` `Hello {name}`, `files` `{count, plural, one {# file} other {# files}}`, `only-en` `English only`, and `bold` `Click <b>here</b>`;
    - `ar`: `greeting` `مرحبا {name}`, and `files` with all six forms (`few {# ملفات}`);
  - the command `lingo.start { delayMs?, contextLocale? }`, which stores `ctx.locale` as `start`, then `ctx.command('lingo.relay')`, which stores `relay` and `ctx.send`s `lingo.finish` (with `delayMs` when given, and `context: { locale: contextLocale }` when given), which stores `finish`;
  - a schedule `tick` at the start of every hour, whose command `lingo.tick` stores `ctx.locale` as `tick`;
  - the query `lingo.locales.get`, which answers what these stored;
  - the command `lingo.say { key, params? }`, which answers `{ text: ctx.i18n.t(key, params) }`;
  - the error `lingo/MISSING` (title "No such item") and the command `lingo.fail { itemId }`, which throws `ctx.problem('lingo/MISSING', { params: { itemId } })`.
  - the commands `lingo.prefer { locale }`, whose handler sends `kernel.user.preferences.set` with `ctx.command` and answers `{ ok }` or the Problem's `code`, and `lingo.preferences.read`, which answers `ctx.query('kernel.user.preferences.get', {})`.
- "**Lingo Mute**" is `@acme/lingo-mute` (namespace `mute`): no `registerTranslations`, and a command `mute.say { key, params? }` like `lingo.say`.
- "**The help preset**" is A's applied preset with:
  - a page `preset.help` on `/help` (title `$t.help.title`, a text node `$t.help.body`);
  - a nav group `preset.extras` (order 900) and a nav item `preset.nav-help` (page `preset.help`);
  - translations with default `en` and catalogs `en` and `ar`.
- **Workspace folders and the home folder** are temporary folders, never the real `~/.kvman` or `~/kvman`.
