# M1.7 — HTTP: test cases

Read: `04`; `02` §2.9 (web files); ADR 0009 (M1.7: HTTP tests come with the CLI, Origin matches its Host, file routes name their workspace, downloads are attachments, uploads, bodies, the web home, the stream).

HTTP tests run against a real kvman child process (`12` §12.1), which exists once the CLI does. So the route scenarios below are written now and tested in M1.8 through the CLI (ADR 0009, 35), in `packages/cli/test/http/`. M1.7 unit-tests the pure parts in `packages/kernel/test/http/`, and runs the HTTP benchmark in-process against a real listener.

## Happy path

### M1.7-H1 — every route answers as §4 says
- **Given** kvman running a `path:` extension with a public command, a public query, a `kvman.web` folder, and `kernel.web.home` set to its namespace
- **When** each route is called: a sync command, an async command, a query, `GET /api/jobs/:id`, `POST /api/jobs/:id/cancel`, an upload, a download, `GET /api/locales/ar`, `/`, and `/web/<namespace>/<file>`
- **Then** each answers its §4 shape: `{ ok: true, output, jobId }`, `{ ok: true, jobId }`, `{ ok: true, job }`, `{ ok: true }`, `{ ok: true, file }`, the raw content, `{ ok: true, catalog }`, and the web files
- Test: `packages/cli/test/http/routes.test.ts` (M1.8)

### M1.7-H2 — a foreign Host or Origin gets FORBIDDEN_ORIGIN
- **Given** kvman running
- **When** a request comes with the Host `evil.com`, the Host `evil.com:<port>` (DNS rebinding), or the Origin `http://evil.com`
- **Then** each gets the envelope with `FORBIDDEN_ORIGIN`, whose params echo nothing
- Test: `packages/cli/test/http/security.test.ts` (M1.8)

### M1.7-H3 — the stream delivers a nested job's progress, then the result
- **Given** an async command that waits, sends a progress chunk, and runs a nested query that sends one too
- **When** its stream is opened before the chunks
- **Then** it gets both `progress` events, `{ source, data }`, then one `result` event with the output, and closes
- Test: `packages/cli/test/http/stream.test.ts` (M1.8)

### M1.7-H4 — a finished job's stream answers at once
- **Given** an async job that has ended
- **When** its stream is opened
- **Then** it gets the `result` event at once and closes
- Test: `packages/cli/test/http/stream.test.ts` (M1.8)

### M1.7-H5 — a sync call whose client disconnects ends cancelled
- **Given** a sync command that waits for its signal, and a `kernel.job.cancelled` handler
- **When** its client disconnects
- **Then** the handler records the job, cancelled
- Test: `packages/cli/test/http/routes.test.ts` (M1.8)

### M1.7-H6 — a path outside a web folder gets 404
- **Given** a web folder, and a symbolic link in it to a file outside
- **When** `/web/<namespace>/..%2f..%2fsecret.txt` and the link are requested
- **Then** both get 404, and the outside file is never served
- Test: `packages/cli/test/http/static.test.ts` (M1.8); `packages/kernel/test/http/static-files.test.ts` (M1.7)

### M1.7-H7 — the HTTP benchmark meets its target
- **Given** kvman's HTTP server in-process with a no-op public command
- **When** `pnpm bench:check` posts it over a kept-alive connection
- **Then** p50 ≤ 5 ms and p99 ≤ 20 ms (`12` §12.3)
- Test: `bench/http-noop.ts` (run by `pnpm bench:check`)

## Edge cases

### Calls (`04` §4.1, ADR 0009, 40)

| Id | Given | Then |
|---|---|---|
| M1.7-E1 | a query name on the commands route, a command name on the queries route, an unknown name, and a private name | `NOT_FOUND` three times, then `NOT_PUBLIC`, without a `jobId` (`packages/cli/test/http/routes.test.ts`, M1.8) |
| M1.7-E2 | a body over the target's `maxInputBytes`, by its Content-Length or by its bytes | `TOO_LARGE` with the limit, and the rest of the body is never read (`packages/kernel/test/http/request-body.test.ts`) |
| M1.7-E3 | a body that isn't JSON; a JSON body with an unknown key, without `input`, or with `async` on a query | 400 with `VALIDATION_FAILED`; `VALIDATION_FAILED` (`packages/kernel/test/http/request-body.test.ts`) |
| M1.7-E4 | an input that fails its schema, and a closed `workspaceId` | the first carries its `jobId`; the second is `NOT_FOUND` without one (`packages/cli/test/http/routes.test.ts`, M1.8) |
| M1.7-E5 | a sync call still waiting for a worker slot when its client disconnects | it never runs, and `kernel.job.cancelled` is queued for it (`packages/cli/test/http/routes.test.ts`, M1.8) |

### Security (`04` §4.2, ADR 0009, 36) — `packages/kernel/test/http/own-origin.test.ts`

| Id | Given | Then |
|---|---|---|
| M1.7-E6 | the Hosts `127.0.0.1:<port>` and `localhost:<port>`, another port, and no Host | the first two pass; the others fail |
| M1.7-E7 | an Origin equal to `http://` plus the Host, the other kvman name, `https://…`, `null`, and none | the first and none pass; the others fail |

### Files (`04` §4.1, ADR 0009, 37–39)

| Id | Given | Then |
|---|---|---|
| M1.7-E8 | an upload without `workspaceId`, without `name`, or into a closed workspace | `VALIDATION_FAILED`, `VALIDATION_FAILED`, `NOT_FOUND` (`packages/cli/test/http/files.test.ts`, M1.8) |
| M1.7-E9 | an upload without Content-Type | the file's type is `application/octet-stream` (`packages/cli/test/http/files.test.ts`, M1.8) |
| M1.7-E10 | a streamed body over its limit | `TOO_LARGE`, and the partial file is removed (`packages/kernel/test/http/request-body.test.ts`) |
| M1.7-E11 | a download without `workspaceId`, and of another workspace's file | `VALIDATION_FAILED`; `NOT_FOUND` (`packages/cli/test/http/files.test.ts`, M1.8) |
| M1.7-E12 | a file named `nöte "x".html` | the download is an attachment with an ASCII `filename` and the UTF-8 `filename*`, with nosniff (`packages/kernel/test/http/attachment.test.ts`) |

### The stream (`04` §4.4, ADR 0009, 42) — `packages/kernel/test/http/job-events.test.ts`

| Id | Given | Then |
|---|---|---|
| M1.7-E13 | chunks before and after the client connects, then the job ends | only the later chunks, then `result` |
| M1.7-E14 | a job that fails, and one that is cancelled | `problem` with its Problem; `problem` with `CANCELLED` |
| M1.7-E15 | a client that leaves, or kvman stopping, while the job runs | the stream ends without a final event, and stops watching the job |
| M1.7-E16 | a stream of an unknown id or a sync job's id | the envelope with `NOT_FOUND` (`packages/cli/test/http/stream.test.ts`, M1.8) |

### Static files and the rest (`04` §4.1, ADR 0009, 41)

| Id | Given | Then |
|---|---|---|
| M1.7-E17 | a nested file, `..` in plain and encoded form, a symbolic link out, a missing file, a folder, and a NUL byte | only the nested file is a file of the folder (`packages/kernel/test/http/static-files.test.ts`) |
| M1.7-E18 | an app route like `/some/page` | the home extension's `index.html` (`packages/cli/test/http/static.test.ts`, M1.8) |
| M1.7-E19 | web mode whose `kernel.web.home` extension is missing, or has no `kvman.web` | the start fails `EXTENSION_INVALID` (`packages/cli/test/http/static.test.ts`, M1.8) |
| M1.7-E20 | an unknown `/api/…` route, and a missing web file | the envelope with `NOT_FOUND`; a plain 404 (`packages/cli/test/http/routes.test.ts`, M1.8) |
| M1.7-E21 | `GET /api/locales/de`, which no catalog has | `NOT_FOUND` (`packages/cli/test/http/routes.test.ts`, M1.8) |
