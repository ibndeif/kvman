Earlier tests that M2.12 changes:

- **The kernel schema version** is 6 wherever a test reads it (ADR 0163's indexes).
- **The event stream's `ui` message** accepts `workspaceId` (the M0.4 protocol test of the SSE schemas).
- **`M2.3-H6`** keeps its assertions; its notification is proven by M2.12-H5.
- **`M2.7-E34`** leaves the kernel's `ui.notify` row of the quarantine notification out of its "no kernel message ran" check (`type NOT LIKE 'ui.%'`).
- **`M2.7-E36`** and **M1.6's schema test** read the latest kernel schema version instead of 5, and use one past it for `SCHEMA_TOO_NEW`.
- **The `EventHub` test harnesses** (`isolation/harness.ts`, `ui/registry-http.ts`, `daemon/boot.test.ts`) pass the kernel clock (`now`), which the tray count in `hello` needs; the model kernel passes `NotificationQueries`.

Not in M2.12:

- Drawing toasts and the tray, attention pinning on screen, desktop alerts, error toasts for a person's own click, and bidi stripping: the shell (M3.8).
- The testkit's `ui` recorder and `asUser()`: M2.13. Tests here read the tray with `kernel.notifications.list` and the stream through an `EventHub` sink.
- `kernel.message.discard`: the inspector (M5.4).

Where the tests live:

- **Sends, the tray, and muting**: `packages/testkit/test/notifications/`, on a harness that installs the fixtures below into the M2.3 workspace fixture (workspaces A and B, the manual kernel clock), with an `EventHub` whose stream sink records every message.
- **Kernel notifications**: `packages/testkit/test/notifications/kernel-notices.test.ts`, `packages/testkit/test/supervision/quarantine-notice.test.ts` (the M1.7 host harness), and `packages/testkit/test/reload/migration-notice.test.ts` (the M2.7 reload harness).
- **Protocol shapes**: `packages/protocol/test/notifications.test.ts`. **Kernel schema**: `packages/kernel/test/storage/kernel-schema-6.test.ts`.

Terms:

- "**Person**" is `user:local`; "**the tab**" is `user:local/client:c1`.
- "**Herald**" is `@acme/herald` (namespace `herald`), enabled in A and B, shared isolation unless a scenario says sandboxed. It requests `ui` and `calls: ['crier.shout', 'crier.approve']`. It registers:
  - `herald.emit { sends: Array<{ kind: 'toast' | 'notify' | 'dismiss' | 'navigate', value }>, note?: string, via?: 'send' | 'command', onReply?: boolean }`, access `all`. It writes `note` to its kv when given, then makes each send with `ctx.ui.*`, or with `ctx.command('ui.<kind>', …)` for `via: 'command'`. With `onReply: true` it uses `ctx.send('ui.<kind>', …, { onReply: 'herald.replied' })`. It answers `{ replies }`, the `ctx.command` answers in order.
  - `herald.replied` (internal), which stores each continuation payload in the kv log `replies`;
  - `herald.relay { sends }`, which `ctx.send`s `herald.emit { sends }`;
  - `herald.emit-global` (scope `global`), like `herald.emit`;
  - `herald.fail`, with `maxAttempts: 2`: it throws `INTERNAL` while its kv `healed` is unset, else answers `{ ran: true }`;
  - `herald.heal`, which sets `healed`;
  - `herald.fail-later`, which `ctx.send`s `herald.fail` with `onReply: 'herald.replied'`;
  - `herald.fail-global` (scope `global`), which always fails; `herald.emit-then-fail`, which emits like `herald.emit`, then fails retryably until healed;
  - `herald.state.get`, answering `{ note, replies, healed }`, and `herald.call { type, payload, kind }`, answering `{ result }` or `{ code }`;
  - `herald.redo` (access `all`), `herald.answer` (access `user`), `herald.tick` (access `internal`), and `herald.api` (access `extensions`);
  - entities:
    - `herald.item` (idField `id`, route `/items/{{ $item.id }}`, page `herald.item-page` on `/items/:itemId`);
    - `herald.pair` (route `/pairs/{{ $item.group }}/{{ $item.id }}`, page on `/pairs/:group/:pairId`);
    - `herald.plain` (no route).
- "**Crier**" is `@acme/crier` (namespace `crier`), enabled in A, with `ui`. It registers:
  - `crier.emit` (like `herald.emit`);
  - `crier.shout` (access `all`) and `crier.approve` (access `user`);
  - the entity `crier.thing` (route `/things/{{ $item.id }}`).
- "**Quiet**" is `@acme/quiet` (namespace `quiet`), enabled in A, without `ui`. Its `quiet.emit` writes kv `note`, then calls `ctx.ui.notify`.
- "**A notice**" is `{ title: '$t.notify.done' }`, with the fields a scenario adds.
- "**The tray of A**" is `kernel.notifications.list { workspaceId: A }` sent by the person.
