# QA 20 — the UI review (ADR 0013)

Asked: an answered `ask` question shows its JSON; review and fix every Arabic text; check the whole UI, and the Settings page most of all. Decided in ADR 0013; plan 02 §2.11, plan 06 §6.6 and §6.7, plan 08 §8.1 and §8.7. This file is the contract; every scenario's test name starts with its id.

*Changed by QA 21 (ADR 0014): the Settings page now holds only kvman's own settings, so the scope switch (H4, H7, E3, E4), an extension's rows (H5, H6, H8, H11, E5, E6), and the secrets (E7) are on each extension's page, where their tests now run; the search (H10) filters kvman's own rows; and the Extensions page lists no command or query (E10).*

## Happy path

- **QA20-H1 An answered choice shows its answer.** *Given* a stored `ask choice` call with three options and its result `{ "selected": ["drag", "core"], "other": "Dark mode too" }`, *then* the message shows an answered card and no call card: the prompt, the three options in the question's order with `core` and `drag` marked chosen, the other answer, and no JSON. `extensions/kvcoder/test/web/answered-card.test.ts`
- **QA20-H2 An answered text or confirm shows its answer.** *Given* results `{ "text" }` and `{ "confirmed" }`, *then* the card shows the text with its line breaks, and Yes or No. `extensions/kvcoder/test/web/answered-card.test.ts`
- **QA20-H3 Enter sends a text answer.** *When* the person presses Enter in a text question's field, *then* the card says `{ text }`. `extensions/kvcoder/test/web/answered-card.test.ts`
- **QA20-H4 The Settings page has one scope switch.** *Given* the workspace `ahmed`, *then* the page shows `scope-global` "All workspaces" (pressed) and `scope-workspace` "Only ahmed", and no row has a scope button or a Save button. `extensions/kvwebui/test/web/settings-page.test.ts`
- **QA20-H5 A select saves on change.** *When* the person picks `dark` for `kvwebui.theme`, *then* `kernel.settings.set { key, value: 'dark', scope: 'global' }` runs once, the row shows `setting-saved`, then `setting-changed` "Changed" and `setting-reset`; Reset runs `kernel.settings.reset { key, scope: 'global' }`. `extensions/kvwebui/test/web/settings-page.test.ts`
- **QA20-H6 A field saves on Enter and on leaving it.** *When* the person types 50 into `notes.pageSize` and presses Enter, and later types 60 and leaves the field, *then* each sends one `kernel.settings.set`; leaving it with the value in effect sends nothing. `extensions/kvwebui/test/web/settings-page.test.ts`
- **QA20-H7 "Only <workspace>" stores a workspace value.** *When* the page is on the workspace and the person changes `notes.pageSize`, *then* the call has `scope: 'workspace'`, the row shows "Changed for ahmed", and its reset "Use the value for all workspaces" runs `kernel.settings.reset { key, scope: 'workspace' }`. `extensions/kvwebui/test/web/settings-page.test.ts`
- **QA20-H8 Options are named from the catalog.** *Given* `notes.mode` with the enum `['auto', 'ask']` and the catalog text `notes.mode.options.auto`, *then* its options read that text and `ask`; picking the first sends `'auto'`. `extensions/kvwebui/test/web/settings-controls.test.ts`
- **QA20-H9 Language is a list of the installed languages.** *Then* `kernel.language` is a select whose options are `English` and `العربية`; picking Arabic sets `kernel.language` to `ar` globally and the page turns right to left. `extensions/kvwebui/test/web/settings-controls.test.ts`
- **QA20-H10 Search filters the settings.** *When* the person types a word of one setting's title, description, or key in any case, *then* only matching rows show, a group with none is hidden with its link, and the Secrets section is hidden; a word nothing has shows "No setting matches."; clearing it brings everything back. `extensions/kvwebui/test/web/settings-controls.test.ts`
- **QA20-H11 The key is in the row's details.** *Then* each row's `setting-key` and `setting-source` are inside its `setting-details`, and nowhere else in the row. `extensions/kvwebui/test/web/settings-page.test.ts`
- **QA20-H12 An answered choice in the real app.** *Given* a chat in Chromium whose model asks an `ask choice` question, *when* the person ticks two options and answers, *then* the conversation shows the answered card with those two options chosen, no question card, no call card, and no JSON. `extensions/kvcoder/test/e2e/answered-question.test.ts`

## Edge cases

- **QA20-E1 A skipped or dismissed question shows Skipped.** *Given* the result `{ "dismissed": true }`, or `dismissed by the user`, *then* the card shows the prompt and "Skipped", and no option. `extensions/kvcoder/test/web/answered-card.test.ts`
- **QA20-E2 Anything that isn't an answer keeps the call card.** *Given* a failed `ask choice`, an `ask help`, and an `ask text` result that isn't JSON, *then* each shows the call card. `extensions/kvcoder/test/web/answered-card.test.ts`
- **QA20-E3 A workspace's own value can't be edited from "All workspaces".** *Given* `notes.pageSize` set for the workspace, *then* on "All workspaces" its control is disabled and `setting-own-value` names the workspace; on the workspace it is enabled. `extensions/kvwebui/test/web/settings-page.test.ts`
- **QA20-E4 A global-only key on the workspace side.** *Given* the page on the workspace, *then* `kvwebui.theme` shows `setting-global-only`, and changing it sends `scope: 'global'`. `extensions/kvwebui/test/web/settings-page.test.ts`
- **QA20-E5 (with QA1-H6 and QA1-E5) A rejected value stays, with its issue.** *When* `kernel.settings.set` fails `VALIDATION_FAILED`, *then* the field keeps the typed value and is marked, `setting-issue` shows the first issue's message, and no toast shows; a valid value then saves and drops the issue. `extensions/kvwebui/test/web/settings-page.test.ts`
- **QA20-E6 A value that can't be read isn't sent.** *When* the person leaves a JSON field holding `[`, *then* the field is marked invalid and no call is made. `extensions/kvwebui/test/web/settings-controls.test.ts`
- **QA20-E7 (with M2.2-E12) Groups, titles, locked keys, and secrets are as before.** The groups and their headings, a title from `<key>.title` or the key, a preset-only key shown locked, and the Secrets section's list, add, and delete. `extensions/kvwebui/test/web/settings-page.test.ts`
- **QA20-E8 The welcome setting has its own title.** Retired by QA 33 (ADR 0022, 1): the setting and both keys are removed; QA33-E4 checks they are gone.
- **QA20-E9 Every choice of kvman's own settings has a name.** *Then* `en` and `ar` have `<key>.options.<value>` for each value of `kvcoder.thinking`, `kvcoder.shell.approval`, and `kvwebui.theme`. `extensions/kvcoder/test/locales.test.ts`, `extensions/kvwebui/test/locales.test.ts`
- **QA20-E10 Names on the Extensions page are left to right.** *Then* an extension's name and version, and a command's name, are in elements with `dir="ltr"`. `extensions/kvwebui/test/web/extensions-page.test.ts`
- **QA20-E11 The Arabic catalogs follow the glossary.** *Then* no Arabic catalog of the kernel, kvai, kvwebui, kvcoder, or kvcustomizer holds a replaced term of ADR 0013 (10) or an Eastern Arabic digit, and none has a Latin letter right after `و`. `test/tooling/arabic-catalogs.test.ts`
- **QA20-E12 Markdown blocks take their own direction.** *Given* Markdown with an Arabic paragraph, an English list, and a code block, *then* each paragraph, heading, list, list item, quote, and table has `dir="auto"`, and a person's message bubble has it too. `extensions/kvwebui/test/web/markdown.test.ts`, `extensions/kvcoder/test/web/answered-card.test.ts`
