# M4.4 — kvwebui embedded in a host: test cases

Read: `06` §6.2, §6.4; `04` §4.2; `03` (the web types); ADR 0100, 9 to 14.

kvwebui is mounted in `happy-dom` against the fake API, as in M2.2. The host is `window.parent`, which is `window` itself in `happy-dom`; a test spies on its `postMessage` and sends messages with `source: window.parent`. A message "from another window" has another `source`.

## Happy path

### M4.4-H1 — `?embed=parent` is taken once, kept for the tab, and shows the page without a frame
- **Given** the fake API with the notes extension
- **When** the app opens at `/notes/list?workspace=w1&embed=parent`, then mounts again at `/notes/list` in the same tab
- **Then** the URL loses `embed` and `workspace`, `sessionStorage` holds `kvwebui.embed` as `parent`, and both mounts show the page with no top bar, nav, panel strip, status bar, or workspace picker; an app opened without it shows them
- Test: `extensions/kvwebui/test/web/embedded.test.ts`

### M4.4-H2 — the embedded page says its workspace to the host
- **Given** an embedded app at `/?workspace=w1&embed=parent`
- **When** it boots, and the workspace is switched to `w2`
- **Then** it posts `{ kind: 'kvman.state', workspaceId: 'w1' }`, then `{ kind: 'kvman.state', workspaceId: 'w2' }`, to `window.parent` with target origin `*`
- Test: `extensions/kvwebui/test/web/embedded.test.ts`

### M4.4-H3 — `kvman.host` posts its messages while embedded
- **Given** a custom component that calls `openFile('/w/a.ts', 12)`, `openDiff('a.ts (proposed)', '/w/a.ts', 'x')`, and `openChange('/w/a.ts')`, and shows `embedded`
- **When** it runs embedded
- **Then** `embedded` is true and the three messages are posted as `kvman.openFile`, `kvman.openDiff`, and `kvman.openChange` with their fields
- Test: `extensions/kvwebui/test/web/embedded-host.test.ts`

### M4.4-H4 — the host's theme sets kvwebui's colors, light or dark, fonts, and size
- **Given** an embedded app
- **When** the parent sends `kvman.theme` with `dark: true`, its colors, fonts `{ sans: 'Ubuntu', mono: 'Fira Code', size: '13px' }`
- **Then** the root has the `dark` class, `--kvwebui-ground` is the background, `--kvwebui-surface` the surface, `--kvwebui-ink` the text, `--kvwebui-primary` the primary, a soft shade is a `color-mix` of its color, `--kvwebui-font-sans` is `Ubuntu`, `--kvwebui-font-mono` is `Fira Code`, and the root font size is `13px`; a later `kvwebui.theme` change doesn't undo the host's dark
- Test: `extensions/kvwebui/test/web/embedded-host.test.ts`

### M4.4-H5 — `kvman.pages` opens the pages menu
- **Given** an embedded app with the notes nav item
- **When** the parent sends `kvman.pages`, then a pick of Settings; and again, then Escape; and again, then a press outside
- **Then** the menu lists the nav items in order, then Settings and Extensions; the pick opens `/kvwebui/settings` and closes the menu; Escape and the press outside close it
- Test: `extensions/kvwebui/test/web/embedded-host.test.ts`

### M4.4-H6 — `kvman.insert` reaches each `onInsert` handler
- **Given** a component that registers an insert handler and shows what it gets, and a second one that removes its handler
- **When** the parent sends `{ kind: 'kvman.insert', text: 'hello' }`
- **Then** the first shows `hello`, and the removed handler gets nothing
- Test: `extensions/kvwebui/test/web/embedded-host.test.ts`

### M4.4-H7 — new windows are handed over under `?embed=parent`
- **Given** the new-window component of M4.1
- **When** it runs in an app opened with `?embed=parent`
- **Then** links and `kvman.open` post `kvman.open` as in M4.1 (M4.1-H3 to M4.1-E4, now with `?embed=parent`)
- Test: `extensions/kvwebui/test/web/new-windows.test.ts`

## Edge cases

### M4.4-E1 — a page that isn't embedded posts nothing and takes nothing
- **Given** an app opened without `?embed=parent`
- **When** it boots, its component calls the three `kvman.host` opens, and the parent sends `kvman.theme`, `kvman.pages`, and `kvman.insert`
- **Then** nothing is posted, `embedded` is false, and nothing changes
- Test: `extensions/kvwebui/test/web/embedded-host.test.ts`

### M4.4-E2 — a message from another window, or of another shape, changes nothing
- **Given** an embedded app
- **When** `kvman.theme` comes from another window, and from the parent with a missing color, `kvman.insert` without text, and a `kind` kvwebui doesn't know
- **Then** no variable is set, no handler runs, and nothing fails
- Test: `extensions/kvwebui/test/web/embedded-host.test.ts`

### M4.4-E3 — the old `?open=parent` is no handoff
- **Given** the fake API
- **When** the app opens at `/?open=parent`
- **Then** it isn't embedded and the parameter stays in the URL
- Test: `extensions/kvwebui/test/web/embedded.test.ts`

### M4.4-E4 — the host's listener ends with the app
- **Given** an embedded app, then unmounted
- **When** the parent sends `kvman.insert`
- **Then** no handler runs
- Test: `extensions/kvwebui/test/web/embedded-host.test.ts`
