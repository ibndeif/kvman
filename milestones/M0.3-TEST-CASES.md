# M0.3 — Protocol: extensions, presets, LLM: test cases

Read: `05` §5.3–§5.8, §5.11–§5.12, `06` §6.1, `07` §7.3; ADRs 0013 (manifest recording), 0014 (LLM messages), 0015 (stage result), 0016 (small grammars), 0017 (preset secrets), 0018 (blob ids).

All tests live in `packages/protocol/test/`. The UI part of the pdf manifest fixture is checked for ids and descriptions only; M0.4 gives it the full shapes of `08` §8.5 (ADR 0013). The `pdf.fileCard` component has no `props` yet: its `z.action()` prop is written in M0.4, once that milestone fixes how `z.action()` appears in JSON Schema. Every new schema is also covered by M0.2-H1, which converts every exported schema with `z.toJSONSchema`.

## Happy path

### M0.3-H1 — the pdf manifest validates
- **Given** `test/fixtures/pdf-manifest.json`: every registration of `05` §5.2 recorded by hand as the manifest of `05` §5.12 (JSON Schemas converted with Zod 4, blob ids per ADR 0018, defaults written per ADR 0013)
- **When** it is parsed with the manifest schema
- **Then** it validates and round-trips
- Test: `packages/protocol/test/manifest.test.ts`

### M0.3-H2 — the kiosk preset validates
- **Given** `test/fixtures/kiosk-preset.json`: the preset of `07` §7.3, completed with the fields its excerpt leaves out (`presetVersion`, `id`, `name`, `revision`, `extensions`)
- **When** it is parsed with the preset schema
- **Then** it validates and round-trips
- Test: `packages/protocol/test/preset.test.ts`

### M0.3-H3 — a loose npm range fails with its path
- **Given** the kiosk preset with the source `npm:@acme/pdf@^1.4.2`
- **When** it is parsed
- **Then** it fails at `extensions.@acme/pdf.source` with a message naming the exact-version rule
- Test: `packages/protocol/test/preset.test.ts`

### M0.3-H4 — a secret in config fails with its path
- **Given** a preset whose `config['@kvman/llm-providers']` holds `{ baseUrl, apiKey }` and that extension's config JSON Schema marking `apiKey` with `secret: true`
- **When** the preset secret check runs
- **Then** it reports one issue at `config.@kvman/llm-providers.apiKey` and none for `baseUrl` (ADR 0017)
- Test: `packages/protocol/test/preset.test.ts`

### M0.3-H5 — a missing description fails with its path
- **Given** the pdf manifest with the description of its second type removed
- **When** it is parsed
- **Then** it fails at `types.1.description`
- Test: `packages/protocol/test/manifest.test.ts`

## Edge cases

### Manifest (`05` §5.3, §5.5, §5.12, ADRs 0013, 0016) — `packages/protocol/test/manifest.test.ts`

| Id | Given | Then |
|---|---|---|
| M0.3-E1 | `manifestVersion: 2` | rejected at `manifestVersion` with "requires a newer kvman" |
| M0.3-E2 | a handler reference that does not name its registration (`command:pdf.other` on `pdf.translate`), and a malformed reference | rejected at `types.N.handler`; `subscription:`, `migration:`, and `provider:` references of the right form are accepted |
| M0.3-E3 | lane templates: the four examples of `02` §2.6 | accepted; a template with no placeholder, a `$state.x` path, `$message.other`, or unbalanced braces is rejected |
| M0.3-E4 | capability requests: `calls` without `types`, `llm` with `types`, `calls` with the pattern `*`, an unknown capability name | rejected each |
| M0.3-E5 | an isolation request of `sandboxed` | rejected (only `shared` and `dedicated` are requested); `null` is accepted |
| M0.3-E6 | a live event with a `payload`, a live event without `chunk`, a durable event with a `chunk` | rejected each |
| M0.3-E7 | a command with `timeoutMs` over 24 h, `concurrency: 0`, or `retention: '7 days'` | rejected each; `retention: '7d'` is accepted |
| M0.3-E8 | a slash name that is not kebab-case, and a query `agentTool` with `dangerous` | rejected each |
| M0.3-E9 | a schedule with both `every` and `cron`, with neither, and private names `Files`, `history:*:x` | rejected each; `history:*`, `childRuns`, `every: '1h'` are accepted |
| M0.3-E10 | an error code outside `<ns>/UPPER_SNAKE`, and a UI entry without a description | rejected at `errors.0.code` and `ui.pages.0.description` |

### Capabilities and sources (`05` §5.7, `06` §6.1) — `packages/protocol/test/capabilities-and-sources.test.ts`

| Id | Given | Then |
|---|---|---|
| M0.3-E11 | a `Capabilities` grant with every requested kind and both derived lists | round-trips; `calls` without `types`, and isolation `none`, are rejected |
| M0.3-E12 | sources `npm:@acme/pdf@1.4.2`, `npm:pdf-lite@2.0.0-beta.1`, `git:https://host/repo.git#<40 hex>`, `git:ssh://git@host/repo.git#<40 hex>`, `builtin:@kvman/agent`, `dev:acme-pdf@3`, `local:<64 hex>` | accepted |
| M0.3-E13 | sources `npm:@acme/pdf@latest`, `npm:@acme/pdf@~1.4`, `npm:@acme/pdf`, `git:https://host/repo.git#main`, `git:file:///repo#<40 hex>`, `dev:@acme/pdf@1`, `dev:acme-pdf@0`, `local:abc`, `@acme/pdf`, `file:../pdf` | rejected each |
| M0.3-E14 | a preset entry whose `integrity` does not fit its source (a `sha512-` integrity on a git source, an integrity on a `dev:` source, no integrity on an npm source) | rejected each at `extensions.<name>.integrity` |

|---|---|---|

### LLM (`05` §5.11, ADR 0014) — `packages/protocol/test/llm.test.ts`

| Id | Given | Then |
|---|---|---|
