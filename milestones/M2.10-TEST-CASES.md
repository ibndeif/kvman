# M2.10 — UI registration and validation: test cases

Read:

- `05` §5.3 (the UI rows, name sets, `z.text()`/`z.action()`), `06` §6.3 (the UI rules), `08` §8.4–§8.9, §8.17.
- The parts they cite:
  - `02` §2.4 (access);
  - `03` §3.8 (who may send each `kernel.*` type);
  - `06` §6.4 (enable checks), §6.6 (reload step 1);
  - `07` §7.3–§7.4 (preset pages, `hidden`, `labels`, `layout.order`, `app.home`);
  - `13` §13.2 (`EXT_MANIFEST_INVALID`, `EXT_REQUIRES_MISSING`, `EXT_IN_USE`, `ROUTE_CONFLICT`, `PRESET_REFERENCE_MISSING`, `VALIDATION_FAILED`).
- ADRs 0023, 0024, 0026, 0029, 0043, 0107, 0109, 0110, 0111, 0112, 0123, 0151, and 0156–0158.

Earlier tests that M2.10 changes, each because a rule M2.10 now enforces refuses its old data:

- **The M0.3 fixture** `packages/protocol/test/fixtures/pdf-manifest.json` records its component props in the input view (ADR 0156), without `additionalProperties: false`.
- **M1.3-H1 and M1.3-H2** record the whole pdf example (`pdf-ui-extension.ts`): its entity's route must open one of its pages (05 §5.3), so the pdf example without its pages no longer records.
  - M1.3-H1 still checks that the non-UI calls produce the fixture's non-UI sections.
  - M1.3-H1's comparison now includes the fixture's `ui`.
- **M1.3-E4** registers a page on `/files/:fileId` for its entity's route.
- **M2.8-H2**'s preset has a page on `/`, and **M2.8-E36**'s patch moves `app.home` to the page that replaces `/help`: `app.home` names an active page (ADR 0157).
- **M2.8-E48** expects the new warnings for `hidden` ids that nothing enabled has (06 §6.3).
- **M2.1-E24** renames the upload's command along with `pdf.import`: a view's command targets are checked (ADR 0157).

Not in M2.10:

- The widget rule of `06` §6.3 (a widget never targets a `user` or `internal` type): a `WidgetDef` declares no calls, so nothing is checked statically; the widget bridge enforces it (M3.7).
- Catalog rules (`$t` keys, ICU): M2.11.
- `since` (ADR 0156).

Where the tests live:

- **Pure pieces**, in `packages/kernel/test/ui/`: route patterns and clashes, composite graphs (cycles and depth), binding paths against JSON Schemas, values holding bindings.
- **Recording and the manifest's own rules**, in `packages/testkit/test/recording/ui-recording.test.ts` and `packages/testkit/test/validation/ui-*.test.ts`, through `recordExtension` and `validateManifest`.
- **Against a workspace**, in `packages/testkit/test/ui/`: a runtime with installed fixtures (ADR 0114), workspaces A and B with applied presets, and `kernel.validate { workspaceId }`.
- **The schema endpoint**, in `packages/testkit/test/schema/contributions.test.ts`.

Terms:

- "**Person**" is `user:local`, an administrator.
- "**Kit**" is `@acme/kit` (namespace `kit`). It registers:
  - a public composite `kit.card` (props `{ title: z.text(), count?: number, onAction?: z.action() }`, children `any`);
  - a private composite `kit.secret`;
  - a slot `kit.tray` (accepts `panel`, props `{ itemId: string }`);
  - an entity `kit.item` (schema `{ id, name }`);
  - a renderer target `kit.entry` (item `{ id, text }`);
  - a query `kit.items.list` (access `all`, output `{ items: [{ id, name }] }`);
  - a page `kit.home` on `/kit`.
- "**Shop**" is `@acme/shop` (namespace `shop`). Requesting `calls: ['kit.items.list']` and `requireComponents(['kit.card'])`, it registers:
  - a page `shop.home` on `/shop` using `kit.card` (a command action passed as `onAction`, a declared query `items` of `kit.items.list`);
  - a panel `shop.tip` in `kit.tray` reading `$slot.itemId`;
  - an action `shop.inspect` on `kit.item` reading `$item.name`;
  - a renderer `shop.line` for `kit.entry` reading `$item.text`.
- "**Shop Lite**" is a Shop build without `shop.home` and without `requireComponents`: its panel, action, and renderer only.
- "**Loop A**" and "**Loop B**" are `@acme/loop-a` and `@acme/loop-b`: each has a public composite that uses the other's, with `requireComponents` naming it.
- "**Twin**" is `@acme/route-twin`, a page on `/kit`.
- **Workspace folders and the home folder** are temporary folders, never the real `~/.kvman` or `~/kvman`.
