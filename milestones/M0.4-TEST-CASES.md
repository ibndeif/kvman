# M0.4 — Protocol: UI contract: test cases

Read: `08` §8.3–§8.9, §8.11, §8.15–§8.16, `12` §12.3, §12.7; ADRs 0023 (`z.text`/`z.action` JSON Schema), 0024 (`parents`), 0025 (schema endpoint), 0026 (binding grammar), 0027 (SSE event), 0028 (`muted` text), 0029 (`childCount`, input controls).

All tests live in `packages/protocol/test/`. View validation here is structural: built-in components, their props, children, parents, child counts, bindings, conditions, and actions. Referential checks (extension components' props, authority, routes, keys in catalogs) belong to M2.10; a component name with a namespace (`pdf.viewer`) is accepted here and checked there.

## Happy path

### M0.4-H1 — the pages of `08` §8.21 validate
- **Given** the Files page and the file-detail page of `08` §8.21 (the fixtures `pdf-manifest.json` already holds)
- **When** each is parsed as a `PageDef`
- **Then** both validate and round-trip
- Test: `packages/protocol/test/ui-views.test.ts`

### M0.4-H2 — every component spec's example validates against its own props
- **Given** the spec of every built-in component of `08` §8.8 (each with `since: '2.0.0'` and one example)
- **When** each example is validated as a view node in a place its spec allows (inside its parent for `tab` and `menuItem`, inside a composite that declares children for `children`)
- **Then** every example is valid, and the specs cover exactly the components of `08` §8.8
- Test: `packages/protocol/test/ui-components.test.ts`

### M0.4-H3 — a tab outside tabs fails with its path
- **Given** a page whose view is a `stack` holding a `tab`
- **When** the page is parsed
- **Then** it fails at `view.children.0` with a message that `tab` appears only inside `tabs`
- Test: `packages/protocol/test/ui-views.test.ts`

### M0.4-H4 — an unknown prop fails with its path
- **Given** a `button` with a prop `colour`
- **When** it is validated
- **Then** it fails at the path of that button node (`children.0`)
- Test: `packages/protocol/test/ui-views.test.ts`

### M0.4-H5 — a malformed binding path fails with its path
- **Given** a `heading` with `text: '$item..name'`
- **When** it is validated
- **Then** it fails at `text`
- Test: `packages/protocol/test/ui-views.test.ts`

## Edge cases

### Bindings (`08` §8.7, ADR 0026) — `packages/protocol/test/ui-bindings.test.ts`

| Id | Given | Then |
|---|---|---|
| M0.4-E1 | the paths `$item`, `$value`, `$query.files.items.0.name`, `$query.files.items.length`, `$t.files.title`, `$locale.dir`, `$slot.sessionId` | parsed into root and segments |
| M0.4-E2 | the paths `$`, `$unknown.x`, `$query`, `$t`, `$item..name`, `$item.name()`, `$item.items.01`, `$item.na me` | rejected each |
| M0.4-E3 | the string `$$5` | a literal, not a binding |
| M0.4-E4 | text with `{{ $query.files.total }}` and with `{{ $query..total }}` | the first is valid; the second fails |
