# M1.2 — SDK: test cases

Read: `03`, `05`, `02` §2.9–§2.10, `04` §4.1; ADR 0009 (M1.2).

The SDK's tests import its source (`packages/sdk/src`). Type tests use vitest's `expectTypeOf`, which `pnpm typecheck` checks; the typed-call test augments `Commands`, `Queries`, and `Settings` for the names `notes.*`, which no other test uses.

## Happy path

### M1.2-H1 — a valid manifest parses
- **Given** the package.json of `02` §2.9 (`@kvman/kvcoder`, `main`, the `@kvman/sdk` peer, and a `kvman` field with `namespace`, `source`, and `dependencies`), plus `scripts` and `devDependencies`
- **When** `extensionManifestSchema` parses it
- **Then** it succeeds, and the other package.json fields are allowed
- Test: `packages/sdk/test/manifest.test.ts`

### M1.2-H2 — a valid preset parses
- **Given** the preset of `02` §2.10, with `bundled`, `npm:1.2.3`, and `path:../y` sources and two settings
- **When** `presetSchema` parses it
- **Then** it succeeds
- Test: `packages/sdk/test/preset.test.ts`

### M1.2-H3 — envelopes parse
- **Given** `{ ok: true, output, jobId }`, `{ ok: true, jobId }`, `{ ok: true, job }`, `{ ok: true, file }`, `{ ok: true }`, and `{ ok: false, problem, jobId }`
- **When** the matching envelope schemas parse them
- **Then** each succeeds
- Test: `packages/sdk/test/envelope.test.ts`

### M1.2-H4 — a declared command gives typed calls; an undeclared name is `unknown`
- **Given** `Commands` augmented with `'notes.add': { input: { text: string }; output: { id: string } }`
- **When** a handler calls `ctx.exec('notes.add', …)` and `ctx.exec('other.thing', …)`
- **Then** the first takes `{ text: string }` and resolves to `{ id: string }`; the second takes and resolves to `unknown`
- Test: `packages/sdk/test/typed-calls.test.ts`

## Edge cases

### Manifest (`02` §2.9, ADR 0009, 6) — `packages/sdk/test/manifest.test.ts`

| Id | Given | Then |
|---|---|---|
| M1.2-E1 | no `main` | fails at `main` |
| M1.2-E2 | no `@kvman/sdk` in `peerDependencies`, or no `peerDependencies` | fails at `peerDependencies` |
| M1.2-E3 | an unknown key in `kvman` (`dependancies`) | fails with an unrecognized key at `kvman` |
| M1.2-E4 | namespaces `KvAi`, `kv.ai`, `kv_ai`, `-kvai` | each fails at `kvman.namespace`; `kv-ai` passes |
| M1.2-E5 | a version `^1.0.0` or a name `Bad Name` | fails at `version` or `name` |
| M1.2-E6 | no `kvman` field | fails at `kvman` |

### Preset (`02` §2.10) — `packages/sdk/test/preset.test.ts`

| Id | Given | Then |
|---|---|---|
| M1.2-E7 | sources `npm:^1.2.3`, `npm:latest`, `git:foo`, `path:` | each fails at its extension |
| M1.2-E8 | an unknown key (`extension`), or no `extensions` | fails |
| M1.2-E9 | no `settings` | passes |

### Problems and envelopes (`05`, `04` §4.1) — `packages/sdk/test/envelope.test.ts`

| Id | Given | Then |
|---|---|---|
| M1.2-E10 | every kernel code, including `INTERRUPTED`; `kvai/NO_MODEL`; and `kvai/no_model`, `NOT_A_CODE`, `KvAi/X` | the kernel codes and `kvai/NO_MODEL` parse; the others fail at `code` |
| M1.2-E11 | `{ ok: true, output, jobId, problem }`, `{ ok: false }`, and a Problem whose `params` hold `Infinity` | each fails |
| M1.2-E12 | `new ProblemError(problem)` | is an `Error` with the Problem's message, and carries the Problem |

### Rows (ADR 0009, 5 and 7) — `packages/sdk/test/rows.test.ts`

| Id | Given | Then |
|---|---|---|
| M1.2-E13 | a job row; the same with `createdAt: 1727665200000`, `status: 'paused'`, or a UUIDv4 id | the row parses; each other fails at its field |
| M1.2-E14 | a file row and a workspace; a file with `size: -1` or owner `{ kind: 'kernel' }` | the first two parse; the others fail |

### Types (`03`) — `packages/sdk/test/typed-calls.test.ts` and `packages/sdk/test/ctx-types.test.ts`

| Id | Given | Then |
|---|---|---|
| M1.2-E15 | a declared query `notes.list`, `execAsync` and `schedule` of `notes.add`, and a declared setting `notes.greeting` | the query is typed; `execAsync` and `schedule` take the command's input; `settings.get('notes.greeting')` resolves to `string`, and an undeclared key to `unknown` |
| M1.2-E16 | the entry of `03` §3.1 | type-checks against `Ctx`; its collection's documents are typed from the schema, with `id`; a `find` filter accepts only primitive top-level fields |
| M1.2-E17 | handlers for `kernel.job.failed` and `kernel.workspace.opened` | receive the base fields plus `problem` and `attempts`, and `{ workspaceId }` |
