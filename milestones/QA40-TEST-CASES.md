# QA 40 — A registered slash command runs on the Chat page (ADR 0028)

Asked: "I have install the newest version of kvman but I found issues where the slash commands are disabled such as build kvman command".

It replaces QA39-E21, whose subject was the greyed registered row. QA25-E6 still holds: kvcoder's own commands stay greyed on the Chat page.

## Happy path

- **QA40-H1 `/build-kvman` on the Chat page starts building kvman in a new chat.** *Given* the `coder` extensions and the Chat page with a ready model, *when* the person types `/build-kvman` and presses Enter, *then* the page opens a new chat that shows the note "Building kvman is on for this chat" and the person's message "I want to change this app.", and its turn's request to the model has the guide in its system prompt. `extensions/kvbuilder/test/e2e/build-kvman.test.ts`
- **QA40-H2 A registered command creates the chat, runs, sends its message, and opens the chat.** *Given* the Chat page and `todo-add` registered with `message`, *when* `/todo-add milk` runs, *then* the calls are, in order, `kvcoder.session.create {}`, `todo.list.start { sessionId, argument: 'milk' }`, and `kvcoder.message.send { sessionId, text: 'milk' }`, with the new chat's id; the page goes to `kvcoder.session` with that id; and the box is empty. `extensions/kvcoder/test/web/slash-chat-start.test.ts`
- **QA40-H3 A bare command sends its translated message.** *When* `/todo-add` runs on the Chat page, *then* `argument` is `''` and the message sent is the translated text of the entry's `message`. `extensions/kvcoder/test/web/slash-chat-start.test.ts`
- **QA40-H4 A command without `message` opens the chat and sends nothing.** *When* `/todo` runs on the Chat page, *then* the chat is created, `todo.list.start` is called with `argument: ''`, `kvcoder.message.send` isn't called, and the page goes to the new chat. `extensions/kvcoder/test/web/slash-chat-start.test.ts`
- **QA40-H5 The picked model and thinking level are set before the command.** *Given* the person picked another model and thinking level on the Chat page, *when* `/todo` runs, *then* `kvcoder.session.configure { sessionId, model, thinking }` is called after `kvcoder.session.create` and before `todo.list.start`; with nothing picked it isn't called. `extensions/kvcoder/test/web/slash-chat-start.test.ts`
- **QA40-H6 On the Chat page the registered rows can run, and kvcoder's own are greyed.** *Given* `build-kvman` and `todo` registered, *when* `/` is typed, *then* the rows are `compact`, `export`, `fork`, `new`, `prompt`, `rename`, `build-kvman`, `todo`; the first six have `aria-disabled` `true` and the last two `false`; the line "Send a first message to use commands" shows; and `/build-kvman` is the highlighted row. Down moves to `/todo`, Down again wraps to `/build-kvman`, and Up wraps to `/todo`. `extensions/kvcoder/test/web/slash-chat-start.test.ts`
- **QA40-H7 Tab completes a registered name, and a click runs it.** *When* `/to` is typed on the Chat page and Tab is pressed, *then* the text is `/todo `; and a click on the `/todo` row runs it as Enter does. `extensions/kvcoder/test/web/slash-chat-start.test.ts`

## Edge cases

- **QA40-E1 The line shows only with a greyed row.** *When* `/bu` is typed on the Chat page, *then* the list has only `/build-kvman`, highlighted, and no line "Send a first message to use commands". `extensions/kvcoder/test/web/slash-chat-start.test.ts`
- **QA40-E2 kvcoder's own commands still run nothing there.** *When* `/co` is typed on the Chat page, *then* the row is greyed and none is highlighted; Enter, Tab, and a click create no chat, run nothing, and keep the text `/co`. `extensions/kvcoder/test/web/slash-chat-start.test.ts`
- **QA40-E3 A blocked box runs nothing.** *Given* the Chat page with no model, *when* `/todo` is typed and Enter is pressed, and its row is clicked, *then* no chat is created, `todo.list.start` isn't called, and the text stays. `extensions/kvcoder/test/web/slash-chat-start.test.ts`
- **QA40-E4 A command that fails toasts and sends nothing.** *Given* `todo.list.start` fails `kvcoder/SESSION_BUSY`, *when* `/todo-add milk` runs on the Chat page, *then* the toast is that Problem's, `kvcoder.message.send` isn't called, and the page doesn't navigate. `extensions/kvcoder/test/web/slash-chat-start.test.ts`
- **QA40-E5 A chat that can't be created runs nothing.** *Given* `kvcoder.session.create` fails, *when* `/todo` runs on the Chat page, *then* the toast is that Problem's, `todo.list.start` isn't called, and the page doesn't navigate. `extensions/kvcoder/test/web/slash-chat-start.test.ts`
- **QA40-E6 A failed configure stops the command.** *Given* a picked model and `kvcoder.session.configure` fails, *when* `/todo` runs, *then* the toast is that Problem's and `todo.list.start` isn't called. `extensions/kvcoder/test/web/slash-chat-start.test.ts`
- **QA40-E7 A message that fails to send toasts, and the page stays.** *Given* `kvcoder.message.send` fails, *when* `/todo-add milk` runs on the Chat page, *then* `todo.list.start` was called, the toast is that Problem's, and the page doesn't navigate. `extensions/kvcoder/test/web/slash-chat-start.test.ts`
- **QA40-E8 An unknown name is still "No such command".** *When* `/nothing` is typed on the Chat page and Enter is pressed, *then* the list says "No such command" with no other line, and nothing runs. `extensions/kvcoder/test/web/slash-chat-start.test.ts`
