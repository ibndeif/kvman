# M0.5 — Spikes and ADRs: test cases

Read: `00` R-Q1, R-Q2, R-Q8, `03` §3.5 (sandboxed processes), `11` §11.5, `14` §14.6; ADR 0007 (checks placed "in CI" run in the local gates).

The SQLite throughput and builder-toolchain spikes ran once, outside the repository, with exactly pinned packages; their method and numbers are in ADRs 0001 and 0004, and their scripts are not kept (product owner's decision). The permission probe is kept in `packages/kernel/scripts/` and runs in `pnpm test`.

## Happy path

### M0.5-H1 — the four ADRs exist with measured results
- **Given** `plan/adr/`
- **When** ADRs 0001 (SQLite), 0002 (permission probe), 0003 (pi-ai), and 0004 (builder toolchain) are read
- **Then** each is accepted and has a Measurements section with numbers: throughput and latencies for 0001, the probe's outcomes for 0002, the pinned package and version for 0003, and step timings and sandbox outcomes for 0004
- Test: `test/tooling/spike-adrs.test.ts`

### M0.5-H2 — the probe script is kept and runs in the gates
- **Given** `packages/kernel/scripts/permission-probe.ts`
- **When** it is run with Node as a script
- **Then** it prints its report, finds no bypass, and exits 0
- Test: `packages/kernel/test/permission-probe.test.ts`

## Edge cases

The sandbox flags are those of `03` §3.5: `--permission`, read access to exactly the files the process needs, and `--no-experimental-sqlite`. Test: `packages/kernel/test/permission-probe.test.ts`.

| Id | Given (inside the sandbox) | Then |
|---|---|---|
| M0.5-E1 | reading a file outside the granted paths (a stand-in `kvman.db`) | denied with `ERR_ACCESS_DENIED` |
| M0.5-E2 | writing a file (no write grant) | denied with `ERR_ACCESS_DENIED` |
| M0.5-E3 | starting a child process | denied with `ERR_ACCESS_DENIED` |
| M0.5-E4 | starting a worker thread | denied with `ERR_ACCESS_DENIED` |
| M0.5-E5 | loading a native addon | denied with `ERR_DLOPEN_DISABLED` |
| M0.5-E6 | loading `node:sqlite` through `import`, `require`, and `process.getBuiltinModule` | unavailable each way |
| M0.5-E7 | the same operations without the sandbox flags (control) | each succeeds (the addon fails only because the file is missing), so the probe detects what the flags block |
| M0.5-E8 | the running Node's permission flags | the report says whether network permission can be enforced; on Node 24 it cannot (`00` R-Q2) |
| M0.5-E9 | a weakened sandbox with one extra `--allow-child-process` | the probe reports `child-process` as a bypass, and the exit code the script derives from that report is non-zero |
