# M0.2 — Protocol: messaging core: test cases

Read: `02` (all), `13` §13.1–§13.2, `04` §4.3 (filter language); ADRs 0008 (filter semantics), 0009 (digest), 0010 (naming grammar), 0011 (`Issue.severity`, `Problem.retryAfterMs`).

All tests live in `packages/protocol/test/`. "Round-trips" means: the schema parses the fixture, the result deep-equals the fixture, and the result survives `JSON.stringify` → `JSON.parse` unchanged.

## Happy path

### M0.2-H1 — every schema round-trips fixtures and converts to JSON Schema
- **Given** valid fixtures for `Address` (all five forms), `Message` (a command, a query, a durable event, a live event, a `ui.*` command with a `target`, a continuation with `onReply`), the kind, delivery-class, access, and priority enums, every `LiveChunk` shape, both `ReplyPayload` forms, `Problem` (with `issues`, `params`, `retryAfterMs`), `Issue` (with and without `severity`), and the request bodies of `12` §12.2 (`POST /commands/:type`, `POST /queries/:type`, `POST /subscriptions`)
- **When** each fixture is parsed and each schema is converted with `z.toJSONSchema`
- **Then** every fixture round-trips and every conversion succeeds
- Test: `packages/protocol/test/schemas.test.ts`

### M0.2-H2 — the grammar checker accepts every example name of `02` §2.4
- **Given** every name written in `02` §2.4: commands (`pdf.translate`, `agent.session.fork`, `kernel.extension.install`, `agent.tool.record`, `agent.turn.expire`, `agent.session.set-model`, `fs.write`, `fs.edit`), queries (`agent.sessions.list`, `pdf.files.list`, `kernel.trust.preview`, `fs.file.get`, `fs.dir.list`, `fs.files.search`), events (`pdf.translated`, `agent.entry.appended`, `kernel.message.dead-lettered`, `pdf.file.translated`), live addresses (`agent.tokens.generated:<id>`, `shell.output.written:<id>`, `pdf.progress.updated:<id>`), the error code `pdf/NOT_FOUND`, and the entity and contribution ids `agent.session`, `agent.chat.sidebar`
- **When** each is checked as its kind
- **Then** no finding is reported
- Test: `packages/protocol/test/naming-grammar.test.ts`

### M0.2-H3 — `pdf.translated` is rejected as a command with the hint
- **Given** the name `pdf.translated`
- **When** it is checked as a command
- **Then** one grammar finding is reported with the message `command names end in an imperative verb` and the hint `did you mean "pdf.translate"?` (ADR 0010)
- Test: `packages/protocol/test/naming-grammar.test.ts`

### M0.2-H4 — the evaluator passes a table test for every operator
- **Given** a table of documents and filters with one or more rows for each of `eq` (implicit and explicit), `ne`, `gt`, `gte`, `lt`, `lte`, `in`, `prefix`, `exists`, and `$or`
- **When** each filter is evaluated against each document
- **Then** every result equals the table's expected value
- Test: `packages/protocol/test/filter.test.ts`

## Edge cases

### Envelope and schemas (`02` §2.1–§2.2, §2.13) — `packages/protocol/test/schemas.test.ts`

| Id | Given | Then |
|---|---|---|
| M0.2-E1 | an address that is none of the five forms (`agent`, `ext:`, `user:local/tab:1`, `proc:`) | rejected |
| M0.2-E2 | a message whose `id`, `correlationId`, or `causationId` is not a ULID | rejected at that path |
| M0.2-E3 | a message whose `context` is over 2 KB (UTF-8 of its JSON) | rejected at `context`; exactly 2,048 bytes is accepted |
| M0.2-E4 | a command or query with `delivery`, and an event without `delivery` | rejected (`delivery` is set on events only) |
| M0.2-E5 | a `target` on anything but a `ui.*` command | rejected at `target` |
| M0.2-E6 | a message with a key the envelope does not define | rejected (envelopes are strict) |
| M0.2-E7 | a `workspaceId` that is not 64 lowercase hex characters | rejected |
| M0.2-E8 | a `LiveChunk` `value` outside 0–1, a chunk with two shapes' keys, and a `{ reset: false }` | rejected |
| M0.2-E9 | a live chunk over 16 KB (UTF-8 of its JSON) | rejected |
| M0.2-E10 | a `ReplyPayload` `{ ok: true }` without `value`, and `{ ok: false }` without `problem` | rejected |
| M0.2-E11 | a `Problem` without `correlationId` or `retryable`, and an `Issue` with a severity other than `error`/`warning` | rejected |
| M0.2-E12 | a command request body without `idempotencyKey`, with `wait` over 60,000 or negative, or with an unknown key | rejected |
| M0.2-E13 | a subscription body whose `events` holds `*` alone or `pdf.*.list`, or whose `live` holds an address without `:<key>` | rejected; `pdf.*` and `pdf.translated` are accepted |

### Filter language (`04` §4.3, ADR 0008) — `packages/protocol/test/filter.test.ts`

| Id | Given | Then |
|---|---|---|
| M0.2-E31 | a missing field and a `null` field | both match `eq: null` and `exists: false`; both fail `exists: true`; both match `ne: 'x'` |
| M0.2-E32 | `gt`/`lt` between a number and a string, a boolean, or a missing field | false |
| M0.2-E33 | strings compared across the Basic Multilingual Plane boundary (`'～'` vs `'😀'`) | ordered by code point (the emoji is greater) |
| M0.2-E34 | `in` against an array field (`tags: ['a', 'b']`) and a scalar field | array: any element in the list matches; scalar: equality with any element |
| M0.2-E35 | dotted paths (`meta.size`, `items.0.id`) and a path through a scalar or a missing object | resolved; a path through a scalar or missing object is missing |
| M0.2-E36 | nested `$or` inside `$or`, and `$or: []` | nested alternatives work; `[]` matches nothing; `{}` matches everything |
| M0.2-E37 | several operators on one field (`{ size: { gt: 1, lt: 10 } }`) | ANDed |
| M0.2-E38 | a filter with an unknown operator, an object operand for `eq`, a non-array `in`, a non-string `prefix`, a non-boolean `exists`, or a key starting with `$` other than `$or` | rejected by the filter schema with the path of the field (or `$or.<n>.<field>`) |
| M0.2-E39 | `prefix` against a number field, and `eq` of `1` against `'1'` | false (no type coercion) |
