# M4.5 — kvcoder in a narrow host: test cases

Read: `08` §8.6 (`kvcoder.file.preview.get`), §8.7 (in a narrow host); `06` §6.4 (`kvman.host`); ADR 0093, 3; ADR 0100, 15 to 19.

The query is tested with the test kernel and its Home folder. The components are tested with the fake `kvman` of kvcoder's web tests, whose `host` records what is asked of it and can insert text. The narrow layout is a CSS rule; its row and buttons are tested in the DOM, and its look by hand.

## Happy path

### M4.5-H1 — the compact header: History, the title, and New chat in one row
- **Given** a chat open in the conversation
- **When** it is shown
- **Then** one row holds the History button (icon only, labelled "History"), the header with the title, and the New chat button (icon only, labelled "New chat"); History opens the chat drawer; New chat opens `kvcoder.chat`; on a new chat the row has History and no header
- Test: `extensions/kvcoder/test/web/compact-header.test.ts`

### M4.5-H2 — `kvcoder.file.preview.get` gives the edited file and writes nothing
- **Given** `notes.txt` in the workspace with `a\nb\n`
- **When** the preview is asked with an edit of `b` to `c`, and with the content `new\n` for `fresh.txt`
- **Then** the answers are `{ path: <real path of notes.txt>, after: 'a\nc\n' }` and `{ path: <real path of fresh.txt>, after: 'new\n' }`; `notes.txt` is still `a\nb\n` and `fresh.txt` doesn't exist
- Test: `extensions/kvcoder/test/file-preview.test.ts`

### M4.5-H3 — "Open diff" on an approval and on a card that ran
- **Given** an embedded page, an approval of `fs edit` on `src/a.ts`, and a card of an `fs edit` on it that ran
- **When** "Open diff" is pressed on each
- **Then** the approval asks `kvcoder.file.preview.get` with the path and edits, then calls `openDiff('a.ts (proposed)', <answer's path>, <answer's after>)`; the card calls `openChange('<workspace>/src/a.ts')`
- Test: `extensions/kvcoder/test/web/host-files.test.ts`

### M4.5-H4 — file paths open in the host
- **Given** an embedded page and cards of a read (from line 24), read-files, an edit that ran (first changed line 7), a write, a find, a list, and a search, and a Changes row
- **When** each path is pressed
- **Then** `openFile` gets the absolute path, at line 24 for the read, 7 for the edit, the first match's line for a search file, and none otherwise; a list's folder isn't a link
- Test: `extensions/kvcoder/test/web/host-files.test.ts`

### M4.5-H5 — inserted text goes to the open composer
- **Given** a chat's composer with `look at` in it, and a new chat's empty composer
- **When** the host inserts `` `src/a.ts:3` ``
- **Then** the chat's draft is `look at\n`` `src/a.ts:3` ``\n` and the empty one's is `` `src/a.ts:3` ``\n`; the composer's text box has the focus
- Test: `extensions/kvcoder/test/web/composer-insert.test.ts`

## Edge cases

### M4.5-E1 — the preview fails as `fs edit` would
- **Given** the workspace
- **When** the preview is asked for an edit whose text isn't in the file, a missing file, a path outside the workspace, and a file that isn't UTF-8
- **Then** they fail `VALIDATION_FAILED`, `NOT_FOUND`, `VALIDATION_FAILED`, and `VALIDATION_FAILED`, and nothing is written
- Test: `extensions/kvcoder/test/file-preview.test.ts`

### M4.5-E2 — outside embedded mode there is no "Open diff" and paths are text
- **Given** the same cards and approval, not embedded
- **When** they are shown
- **Then** there is no "Open diff" and no path button, and the host is asked nothing
- Test: `extensions/kvcoder/test/web/host-files.test.ts`

### M4.5-E3 — a preview that fails is toasted
- **Given** an embedded approval whose preview fails `VALIDATION_FAILED`
- **When** "Open diff" is pressed
- **Then** the Problem's text is toasted and `openDiff` isn't called
- Test: `extensions/kvcoder/test/web/host-files.test.ts`

### M4.5-E4 — a composer that is gone takes no text
- **Given** a composer, then unmounted
- **When** the host inserts text
- **Then** no draft changes
- Test: `extensions/kvcoder/test/web/composer-insert.test.ts`
