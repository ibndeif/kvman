# QA 12 — the artifact panel (ADR 0009, 214–216)

Found by opening a todo page the agent wrote: it was stored as `markdown` (the model left out `"format":"html"`) and showed as text. The product owner asked for Preview and Source, Copy, and artifacts that preview a URL, the agent deciding the format; they chose a format left out is read from the content, this machine only, and a scripts-only frame. Every scenario names its test. Backend tests use the test kernel and the fake model; `test/web/` mounts components in happy-dom; `test/e2e/` drives Chromium against a real kvman.

## Happy path

- **QA12-H1 A page written without a format is stored as html.** *Given* `artifact write '{"id":"app","title":"App"}'` with a body starting `<!DOCTYPE html>`, and another starting `  <html lang="ar">`, *then* each is stored with format `html` (`kvcoder.artifact.get`) and the result card's format is `html`; an explicit `"format":"markdown"` with the same body stays `markdown`. (`extensions/kvcoder/test/artifact-format.test.ts`)
- **QA12-H2 A lone local address written without a format is a url artifact.** *Given* content `http://localhost:8080/` (and `https://127.0.0.1:5173/app?x=1`), no format, *then* it is stored `url` with the address as its content; a sentence containing an address stays `markdown`. (`extensions/kvcoder/test/artifact-format.test.ts`)
- **QA12-H3 A url artifact is written with `format: 'url'`.** *Given* `artifact write '{"id":"app","title":"App","format":"url","content":"http://localhost:8080 "}'`, *then* the stored content is `http://localhost:8080` (trimmed), the result is `{ id, version: 1, created: true, bytes: 21 }`, and `kvcoder.artifact.list` and `get` report `url`. (`extensions/kvcoder/test/artifact-format.test.ts`)
- **QA12-H4 The panel switches between Preview and Source.** *Given* a Markdown and an HTML artifact, *then* Preview is shown first; *when* Source is pressed, *then* the text as stored shows in `[data-test="artifact-source"]` and neither the rendered view nor the frame; *when* Preview is pressed, it returns; *when* another artifact is shown, the panel is back on Preview. (`extensions/kvcoder/test/web/artifact-view.test.ts`)
- **QA12-H5 Copy puts the stored text on the clipboard.** *When* Copy is pressed, *then* `navigator.clipboard.writeText` gets the artifact's content exactly, and a toast says copied; in Chromium with clipboard permission the clipboard reads back the content. (`extensions/kvcoder/test/web/artifact-view.test.ts`, `extensions/kvcoder/test/e2e/artifact-view.test.ts`)
- **QA12-H6 A url artifact previews in a scripts-only frame.** *Given* a `url` artifact `http://localhost:8080/`, *then* Preview is an `<iframe>` with `sandbox="allow-scripts"` (and no `allow-same-origin`), `referrerpolicy="no-referrer"`, and `src="http://localhost:8080/"`; Source shows the address; an "Open in a new tab" link has `target="_blank"` and `rel="noopener noreferrer"`. (`extensions/kvcoder/test/web/artifact-view.test.ts`)
- **QA12-H7 A url artifact shows a page in Chromium.** *Given* a page served on a free local port and an artifact pointing at it, *then* the frame loads it (its text is visible in the frame) and the page can't read kvman's page. (`extensions/kvcoder/test/e2e/artifact-view.test.ts`)

## Edge cases

- **QA12-E1 An address that isn't local is refused on write.** *Given* `"format":"url"` with `https://example.com`, `http://192.168.1.5:3000`, `ftp://localhost`, `javascript:alert(1)`, `http://user:pw@localhost:8080`, two words, or an address over 2 048 characters, *then* each fails `VALIDATION_FAILED` naming what is allowed and nothing is stored. (`extensions/kvcoder/test/artifact-format.test.ts`)
- **QA12-E2 Editing a url artifact re-checks it.** *Given* a `url` artifact and an `edit` that makes it `https://example.com`, *then* it fails `VALIDATION_FAILED` and the artifact is unchanged; an edit that keeps it local succeeds. (`extensions/kvcoder/test/artifact-format.test.ts`)
- **QA12-E3 The panel never frames kvman itself or a non-local address.** *Given* a `url` artifact whose address is on the page's own port (`http://localhost:<own port>/`, also `http://127.0.0.1:<own port>`, and the same through the default port), *or* `https://example.com`, `javascript:alert(1)`, or an address with credentials stored by an older write, *then* no `<iframe>` and no "Open in a new tab" link exist and `[data-test="artifact-url-refused"]` says so; `frameableUrl` returns `undefined` for each and the address for `http://localhost:8080/`. (`extensions/kvcoder/test/unit/artifact-url.test.ts`, `extensions/kvcoder/test/web/artifact-view.test.ts`)
- **QA12-E4 Copy failing says why.** *Given* `navigator.clipboard.writeText` rejects, *then* a toast shows an error and nothing says copied. (`extensions/kvcoder/test/web/artifact-view.test.ts`)
- **QA12-E5 Source works while the content loads.** *Given* the content has not arrived, *then* Copy is disabled and Source shows nothing. (`extensions/kvcoder/test/web/artifact-view.test.ts`)
- **QA12-E6 An older artifact keeps its format.** *Given* a stored `markdown` or `html` artifact, *then* it lists and reads as before, and a `write` that replaces it without a format is read from its new content. (`extensions/kvcoder/test/artifact-format.test.ts`)
- **QA12-E7 Every new text is in both languages.** *Then* `en` and `ar` have the same keys, including Preview, Source, View, the URL format, "Open in a new tab", and the refusal line. (`extensions/kvcoder/test/locales.test.ts`)
- **QA12-E8 The help says the three formats.** *Then* `artifact -h` names `markdown`, `html`, and `url`, says what is read from a format left out, and the prompt's entry for `artifact` mentions a localhost address. (`extensions/kvcoder/test/artifact-format.test.ts`, `extensions/kvcoder/test/prompt.test.ts`)
