# QA 31 — the `delegate` connector and its subagent workers (ADR 0021)

Asked: "replace subagent connector by a brand new connector for delegate", with workers that have "their own configs", specialists that are "a subagent with a predefined system prompt and connectors", and "the user should be able to enable/disable workers". Decided in ADR 0021; plan 08 §8.1, §8.2, §8.4, §8.5, and §8.7. This pass has the `subagent` kind only; the `opencode`, `pi`, and `claude` kinds are QA 32. This file is the contract; every scenario's test name starts with its id.

The scenarios of earlier passes that ran `subagent run` keep their ids and now run `delegate run` with a worker (a test sets `kvcoder.delegate.workers` when it needs a worker with a connector list). Three are retired, since what they checked is gone (ADR 0021, 2): the `fork` half of M2.4-H4 (both runs are now fresh), QA18-H16 and QA18-E24 (the per-call `connectors`, replaced by QA31-H5, QA31-E4, and QA31-E5).

## Happy path

- **QA31-H1 `delegate` replaces `subagent`.** *Then* kvcoder's own connectors are `shell`, `fs`, `artifact`, `background`, `ask`, `delegate`, and `mcp`; the prompt's index has `- delegate: ` and no `- subagent: `; its `run` line is `run  { worker, task, background? }`; and a call to `subagent` gets `There is no connector subagent. The connectors are: …`. `extensions/kvcoder/test/delegate-workers.test.ts`
- **QA31-H2 The shipped workers.** *Given* no setting, *then* `kvcoder.delegate.workers` is `general`, `ui-ux`, `architect`, `tester`, and `reviewer`, each `{ enabled: true, kind: 'subagent', connectors: null, model: null, thinking: null }` with ADR 0021's description and instructions, and `general`'s instructions are empty. `extensions/kvcoder/test/delegate-workers.test.ts`
- **QA31-H3 The index names the workers.** *Then* the `delegate` entry's description ends with `Workers: general (Any separate, self-contained task), ui-ux (Designs screens and flows), architect (Studies the code and proposes a design), tester (Writes and runs tests), reviewer (Reviews changes with a fresh look).` `extensions/kvcoder/test/delegate-workers.test.ts`
- **QA31-H4 A run starts a child with the worker's instructions.** *When* the agent calls `delegate run { worker: 'reviewer', task }`, *then* a child session starts whose first message is the task, whose system prompt has the block `## Worker: reviewer` with the reviewer's instructions after the sections and before `## Connectors`, and whose final answer is the call's result. `extensions/kvcoder/test/delegate-workers.test.ts`
- **QA31-H5 A worker's connectors.** *Given* a worker with `connectors: ['fs']`, *then* its child's index has `fs` and `ask` and no `shell`, and a `shell` call there gets `error VALIDATION_FAILED: shell isn't available in this subagent.` `extensions/kvcoder/test/delegate-workers.test.ts`
- **QA31-H6 A worker's model and thinking.** *Given* a worker with `model: 'fake/other'` and `thinking: 'high'`, *then* the child's `kvai.complete` calls use that model and level; with both `null` they use the parent's. `extensions/kvcoder/test/delegate-workers.test.ts`
- **QA31-H7 `general` has no worker block.** *Then* a `general` child's prompt has no `## Worker:` line. `extensions/kvcoder/test/delegate-workers.test.ts`
- **QA31-H8 A child session names its worker.** *Then* `kvcoder.session.get` of the child has `worker: 'reviewer'`, and a top-level session has no `worker`. `extensions/kvcoder/test/delegate-workers.test.ts`
- **QA31-H9 Turning a worker off.** *Given* `reviewer` with `enabled: false`, *then* the index's `Workers:` doesn't name it, and a run of it fails `kvcoder/WORKER_NOT_FOUND`: `There is no worker reviewer. The workers are: general, ui-ux, architect, tester.` `extensions/kvcoder/test/delegate-workers.test.ts`
- **QA31-H10 The base prompt speaks of workers.** *Then* the prompt has "Hand a separate, self-contained part to a worker of the `delegate` connector" and "what each step uses (a connector, a worker)", and no "to a subagent". `extensions/kvcoder/test/prompt.test.ts`
- **QA31-H11 `delegate` has a cog.** *Then* the connectors list shows `delegate` with its catalog description, a switch, and a "Configure delegate" button, and no `subagent` row. `extensions/kvcoder/test/web/connectors-list.test.ts`
- **QA31-H12 The dialog lists the workers.** *When* the cog is pressed, *then* the dialog shows each worker's name, description, and kind, a switch that is on for an enabled worker, Edit, and Remove, and "Add a worker". `extensions/kvcoder/test/web/delegate-workers.test.ts`
- **QA31-H13 A switch writes `enabled`.** *When* `reviewer`'s switch is pressed, *then* `kernel.settings.set` runs for `kvcoder.delegate.workers` in `kvman.scope` with the same list and `reviewer`'s `enabled` false. `extensions/kvcoder/test/web/delegate-workers.test.ts`
- **QA31-H14 Adding a worker.** *When* the form is saved with a name, a description, instructions, "Only these" with `fs` ticked, a model, and a thinking level, *then* the list is written with the new entry last: `{ name, description, enabled: true, kind: 'subagent', instructions, connectors: ['fs'], model, thinking }`, and a success toast names it. `extensions/kvcoder/test/web/delegate-workers.test.ts`
- **QA31-H15 Editing a worker.** *When* Edit is pressed, *then* the form holds the worker's values with Name fixed; "All", "Same as the chat" for the model, and "Same as the chat" for thinking store `null`. `extensions/kvcoder/test/web/delegate-workers.test.ts`
- **QA31-H16 Removing a worker.** *When* Remove is pressed and confirmed, *then* the list is written without it. `extensions/kvcoder/test/web/delegate-workers.test.ts`
- **QA31-H17 The child's card names its worker.** *Then* a subagent card shows the worker's name beside the task. `extensions/kvcoder/test/web/conversation-stream.test.ts`
- **QA31-H18 In the real app.** *Given* kvman in Chromium, *when* the person opens kvcoder's configuration, presses `delegate`'s cog, and turns `reviewer` off, *then* the row's switch is off, and after a reload it still is. `extensions/kvcoder/test/e2e/configuration.test.ts`

## Edge cases

- **QA31-E1 An unknown worker.** *Then* a run of `nobody` gets `error kvcoder/WORKER_NOT_FOUND: There is no worker nobody. The workers are: general, ui-ux, architect, tester, reviewer.`, and no child starts. `extensions/kvcoder/test/delegate-workers.test.ts`
- **QA31-E2 The old payload.** *Then* `delegate run { task, mode: 'fresh' }` fails `VALIDATION_FAILED` naming `worker` and the unrecognized key `mode`, and ends `The payload of delegate run is\n{ worker, task, background? }`. `extensions/kvcoder/test/delegate-workers.test.ts`
- **QA31-E3 No worker available.** *Given* every worker turned off, or `kvcoder.delegate.workers` set to `[]`, *then* `delegate` isn't in the prompt's index or the `run` tool's connectors, and a call to it gets `There is no connector delegate. The connectors are: …`. `extensions/kvcoder/test/delegate-workers.test.ts`
- **QA31-E4 A child never has `delegate`.** *Given* a worker with `connectors: ['delegate', 'fs']`, *then* its child's index has no `delegate`, and a `delegate` call there gets `error VALIDATION_FAILED: delegate isn't available in this subagent.` `extensions/kvcoder/test/delegate-workers.test.ts`
- **QA31-E5 A connector the chat doesn't have is ignored.** *Given* a worker with `connectors: ['nope', 'fs']`, *then* the run starts and the child has `fs` and `ask`. `extensions/kvcoder/test/delegate-workers.test.ts`
- **QA31-E6 `delegate` turned off.** *Given* `kvcoder.connectors.disabled` names `delegate`, *then* it isn't in the index and a call gets the answer for a connector that doesn't exist; a `subagent` entry in that setting is ignored. `extensions/kvcoder/test/connectors-disabled.test.ts`
- **QA31-E7 The setting is strict.** *Then* setting `kvcoder.delegate.workers` fails `VALIDATION_FAILED` for two workers with one name, a name that isn't lowercase kebab case, an empty description, an unknown key, a `kind` that isn't `subagent`, a `thinking` that isn't a level, and instructions over 16 KB. `extensions/kvcoder/test/delegate-workers.test.ts`
- **QA31-E8 A workspace's list replaces the global one.** *Given* a global list and a workspace list, *then* a chat of that workspace sees only the workspace's workers. `extensions/kvcoder/test/delegate-workers.test.ts`
- **QA31-E9 A child keeps the instructions it started with.** *Given* a child waiting on a question, *when* its worker's instructions are changed and the question is answered, *then* the child's next step still has the old block. `extensions/kvcoder/test/delegate-workers.test.ts`
- **QA31-E10 A worker's unknown model.** *Given* a worker whose `model` no provider has, *then* the child's step fails, and the call's result is `subagent ended failed` as an error. `extensions/kvcoder/test/delegate-workers.test.ts`
- **QA31-E11 The names kvcoder owns.** *Then* registering a connector named `delegate` fails `kvcoder/NAME_TAKEN`, and one named `subagent` registers. `extensions/kvcoder/test/connector-register.test.ts`
- **QA31-E12 `runConnector` and `delegate`.** *Then* `runConnector` gives `delegate help` its text, and `delegate run` exit 1 with "runs only inside a turn". `extensions/kvcoder/test/run-connector.test.ts`
- **QA31-E13 A background run.** *Then* `delegate run { worker, task, background: true }` returns `started <childSessionId>`, its row of `kvcoder.job.list` has `kind: 'subagent'`, and the answer arrives later as a message with `source: { kind: 'subagent', sessionId }`. `extensions/kvcoder/test/background-connector.test.ts`
- **QA31-E14 A name that is taken, or a bad field.** *When* the form is saved with a name already in the list, a name that isn't lowercase kebab case, or no description, *then* the problem shows under its field and nothing is written. `extensions/kvcoder/test/web/delegate-workers.test.ts`
- **QA31-E15 The workspace has its own list.** *Given* "All workspaces" while the workspace has its own value, *then* the dialog says so, and the switches, Edit, Remove, and "Add a worker" are disabled. `extensions/kvcoder/test/web/delegate-workers.test.ts`
- **QA31-E16 Changed, and reset.** *Given* a list set in the scope being edited, *then* the dialog shows "Changed" and a reset, which runs `kernel.settings.reset` for the key in that scope. `extensions/kvcoder/test/web/delegate-workers.test.ts`
- **QA31-E17 No workers.** *Given* an empty list, *then* the dialog says "No workers yet. Add one and the agent can hand it a task." `extensions/kvcoder/test/web/delegate-workers.test.ts`
- **QA31-E18 Both languages.** *Then* every new catalog key has an `en` and an `ar` entry. `extensions/kvcoder/test/locales.test.ts`
