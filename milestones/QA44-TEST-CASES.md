# QA 44 — Compaction that reads the cache, the date on a person's message, and the chat page's scroll (ADR 0032)

Asked: "Develop a plan to fix the caching issues and we need to give the model access to current date, Also we need to fix a ui issue where the chat page has a scorll to empty section".

The tests use the fake model and the kernel's fake clock. A stamp's exact text is tested with fixed offsets (QA44-E3); the tests that go through a step compare with the stamp of the message's own `createdAt` at the computer's offset, so they pass in any time zone.

## Happy path

- **QA44-H1 A person's message reaches the model with its date.** *Given* a new chat, *when* the person sends `hello`, *then* the `user` message of the model request is the stamp of the stored message's `createdAt`, a line break, and `hello`; and `kvcoder.message.list` still returns the content `hello` with no stamp. `extensions/kvcoder/test/message-dates.test.ts`
- **QA44-H2 A later step sends the same text again.** *Given* a turn of two steps (a `shell exec` call, then an answer), *then* the first `user` message of the second request is exactly the first request's; and after a second message, the first message is sent with the same text again and the second with the stamp of its own `createdAt`. `extensions/kvcoder/test/message-dates.test.ts`
- **QA44-H3 The base prompt says what the stamp is.** *Then* the system prompt of a step has the sentence `Each message from the person starts with the date and time it was sent, in brackets; the newest one is the current time.` right after the reply-language line. `extensions/kvcoder/test/message-dates.test.ts`
- **QA44-H4 A summary is asked for with the step's own request.** *Given* a chat past `kvcoder.compactAt`, *when* the next message is sent, *then* the summary's request has the same system prompt and the same tools as the step's request that follows it; its messages are the older messages as a step sends them (stamped `user` messages and the answers), in order, then one last `user` message that is exactly the instruction of ADR 0032, 7; and the summary is stored with its `coversThroughSeq`. `extensions/kvcoder/test/compaction-cache.test.ts`
- **QA44-H5 The page doesn't scroll past a chat that has an answered question.** *Given* a chat where the person answered a choice question, followed by enough messages to fill the list, *when* the conversation is open, *then* the page's `main` has a `scrollHeight` equal to its `clientHeight`, and the message list is the element that scrolls. `extensions/kvcoder/test/e2e/answered-question.test.ts`

## Edge cases

- **QA44-E1 A message that isn't the person's has no stamp.** *Given* a lead that delegates the task `Check it` to a worker, *then* the subagent's request has the `user` message `Check it`, with no stamp (its `source` is a subagent), while the lead's own request has the person's message with its stamp. `extensions/kvcoder/test/message-dates.test.ts`
- **QA44-E2 A message with an image keeps the image.** *Given* a message sent with an image file, *then* the model request's `user` message has a text part that starts with the stamp, then the image part. `extensions/kvcoder/test/message-dates.test.ts`
- **QA44-E3 The stamp's text.** *Then* `2026-10-07T01:55:53.848Z` at +180 minutes is `[Wednesday 2026-10-07 04:55 +03:00]`; at 0 it is `[Wednesday 2026-10-07 01:55 +00:00]`; at -420 it is `[Tuesday 2026-10-06 18:55 -07:00]`, a day before UTC's; at +330 it is `[Wednesday 2026-10-07 07:25 +05:30]`; and `2026-12-31T23:30:00.000Z` at +60 is `[Friday 2027-01-01 00:30 +01:00]`. `extensions/kvcoder/test/message-stamp.test.ts`
- **QA44-E4 A summary with no text failed.** *Given* a chat past `kvcoder.compactAt` and a model that answers the summary's request with a `run` call and no text, *then* the notice `SUMMARY_FAILED` is added with `params: { code: 'kvcoder/SUMMARY_EMPTY' }`, no summary is stored, the call isn't run, and the step goes on to its own answer. `extensions/kvcoder/test/compaction-cache.test.ts`
- **QA44-E5 An earlier summary is sent first.** *Given* a chat that was summarized once and passed `kvcoder.compactAt` again, *then* the second summary's request starts, after the system prompt, with the `user` message `A summary of the earlier conversation:` and the first summary's text, with no stamp, then the older messages, then the instruction. `extensions/kvcoder/test/compaction-cache.test.ts`
- **QA44-E6 The new error has its texts.** *Then* `kvcoder.errors.SUMMARY_EMPTY` is `The model returned no summary.` in English and has an Arabic entry. `extensions/kvcoder/test/locales.test.ts`
