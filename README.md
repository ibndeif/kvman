# kvman

An app that works like a small operating system for every kind of user: a kernel runs extensions, and a preset shapes them into the app a person uses.

**Status:** being redesigned. The kernel is specified in `plan/`, and the core extensions are designed next. There's no code yet. The previous implementation is on the branch `archive/v2`.

```
kvman [--mode web] [--preset coder] [--home <dir>] [--port <n>] [--yes]
```
