# @kvman/kvcoder

The [kvman](https://github.com/ibndeif/kvman) app-building harness: an agent with one `run` tool over connectors, sections, and its conversation UI. It is bundled with kvman, and needs `@kvman/kvai` and `@kvman/kvwebui`.

See [its guides](https://github.com/ibndeif/kvman/tree/main/extensions/kvcoder/docs).
