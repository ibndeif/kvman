# @kvman/kvcustomizer

The [kvman](https://github.com/ibndeif/kvman) extension that customizes kvman from a chat: it builds extensions and presets, and manages the running app. It is bundled with kvman, and needs `@kvman/kvai` and `@kvman/kvcoder`.

See [its guides](https://github.com/ibndeif/kvman/tree/main/extensions/kvcustomizer/docs).
