# @kvman/kvvideo

The [kvman](https://github.com/ibndeif/kvman) extension that makes videos of the person's app from a chat: it records pages in the installed Chrome or Edge, narrates a script with ElevenLabs, OpenAI, or Piper, and joins them with burned-in captions into an MP4 with ffmpeg. It is bundled with kvman, and needs `@kvman/kvcoder` and `@kvman/kvwebui`. Type `/video` in a chat to turn it on.

## Fonts

`fonts/` holds Amiri, IBM Plex Sans Arabic, Lato, and Poppins in their bold weights, each under the SIL Open Font License beside it.
