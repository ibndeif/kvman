A node of the execution map is a task in every word the person and the model read; the field stays `steps`. A press on a task opens a dialog over the page with its details, which follows the task as the map changes, in place of the detail under the diagram. The lead's Plan draws a task after another only when it needs its result, so separate tasks are branches that join at the task that needs them, and its Execute keeps the map live: doing in the same reply as a task's first call, done as soon as its check passed, the map set again when the plan changes, small ready tasks in one reply and a large separate branch to a worker. A reply that changes something (`fs write`, `fs edit`, `shell exec`) while tasks are left and none is doing gets one line of reminder in the last change's result; nothing is refused (ADR 0074).
