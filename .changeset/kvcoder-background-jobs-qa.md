The bash tool takes `mode: 'async'` to run a command in the background; `jobs` lists, reads, and stops those processes, kvcoder records how each ends, and a Running chip in the chat header lets the person see, read the logs of, and stop them (`kvcoder.job.list`, `kvcoder.job.get`, `kvcoder.job.cancel`).
