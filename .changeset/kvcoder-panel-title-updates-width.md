The panel beside a chat has one title that opens a list of the execution map and the artifacts, in place of a row of titles that scrolled sideways. An updated artifact or execution map opens the panel on itself, also when it was closed, and of the two the one updated later is shown. The panel's edge beside the conversation is a handle: dragging it, or the Left and Right keys, set the panel's width from 20 rem to 70% of the chat area, a double-click returns to the starting width, and the browser keeps it under `kvcoder.panelWidth`. The thinking level of the send box is kvcoder's own list, which opens above the box (ADR 0071).
