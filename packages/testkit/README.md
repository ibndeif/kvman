# @kvman/testkit

The tools for building and testing a [kvman](https://github.com/ibndeif/kvman) extension: `createTestKernel`, which runs the real kernel in a test, and the bins `kvman-new` (a new extension project), `kvman-check`, `kvman-preset`, `kvman-preview`, and `kvman-docs`.

```
npx -p @kvman/testkit kvman-new ./notes --name @me/notes --namespace notes
```

Start with [Getting started](https://github.com/ibndeif/kvman/blob/main/docs/developers/getting-started.md).
