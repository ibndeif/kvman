# @kvman/sdk

The extension API of [kvman](https://github.com/ibndeif/kvman): the `ctx` types, `z` (zod), and the shared shapes (preset, extension manifest, Problem, job, envelope). `@kvman/sdk/web` is the API of an extension's web components.

An extension lists it as a peer dependency, and kvman supplies its own copy at run time:

```json
{ "peerDependencies": { "@kvman/sdk": "^0.1.0" } }
```

Start with [Getting started](https://github.com/ibndeif/kvman/blob/main/docs/developers/getting-started.md) and [The SDK](https://github.com/ibndeif/kvman/blob/main/docs/developers/sdk.md).
