# @kvman/kernel

The kernel of [kvman](https://github.com/ibndeif/kvman): jobs, workers, storage, extensions, and HTTP.

It is a dependency of `kvman` and `@kvman/testkit`. An extension never imports it: an extension uses [`@kvman/sdk`](https://www.npmjs.com/package/@kvman/sdk), and tests use [`@kvman/testkit`](https://www.npmjs.com/package/@kvman/testkit).

See [Architecture](https://github.com/ibndeif/kvman/blob/main/docs/developers/architecture.md).
