# ADR 0109 — pi-ai 1.4.0 and its new models

Status: accepted by the product owner on 2026-10-30 ("upgrade pi ai package and include all new models so the user
can use them"). It replaces ADR 0083, 1 (the pi-ai version), amends ADR 0083, 3 (the routers left out by name), and
amends plan 07 (its opening and §7.2).

## Context

kvai pinned `@earendil-works/pi-ai` 1.2.0 (ADR 0083). The latest version is 1.4.0 (2026-10-21). kvai lists pi-ai's
built-in catalog as it is, so a newer pi-ai brings its models with no list of kvai's own.

Comparing the two catalogs' chat models: 1,554 in 1.2.0 and 1,599 in 1.4.0, with 116 new and 71 removed, and no
provider added or removed. Among the new ones are Google's `gemini-4-argon` (also through GitHub Copilot) and
`gemini-pro-latest`; most are Vercel AI Gateway's (62) and OpenRouter's (18). The removed ones are retired versions
(for example `openai-codex/gpt-5.5` and `github-copilot/gpt-5.5`); none is a model the owner's chats use.

One new model is a router OpenRouter prices by the model it picks, `openrouter/pareto-code` ("Pareto Code Router"),
which pi-ai lists at 0, as ADR 0083's limits said would happen. `openrouter/fusion`, already in 1.2.0, is one too.
`openrouter/free` ("Free Models Router") routes only to free models, so its price of 0 is true.

What kvai relies on is unchanged: its source and build typecheck against 1.4.0, every sign-in still takes
`agentName` (ADR 0083, 2), and the new `telemetry` option is off unless a caller passes its own collector, which kvai
doesn't; pi-ai's telemetry package makes no network call. The only other package that changes is
`@earendil-works/pi-telemetry`, 1.2.0 to 1.4.0, pi-ai's own dependency.

## Decisions

1. **pi-ai is 1.4.0** (asked), the latest version, pinned exactly, with every model of its catalog listed by the
   rule of plan 07 §7.2. This replaces ADR 0083, 1.
2. **Two more routers stay out, by name**, as ADR 0083, 3 decided for routers: `openrouter/fusion` and
   `openrouter/pareto-code`, beside `openrouter/auto`, `openrouter/auto-beta`, and `typesafe/jev-router`.
   `openrouter/free` stays listed.

## Limits

- A chat or a setting that names a removed model gets `kvai/MODEL_UNKNOWN` at its next call, as for any model a
  catalog no longer has; the person picks another.
- A router OpenRouter adds later is still listed at 0 until it is named here.

## Verification

Scenario M2.1-E20 extended: the new routers aren't listed and a call to one fails `kvai/MODEL_UNKNOWN`, and
`google/gemini-4-argon`, `github-copilot/gemini-4-argon`, `google/gemini-pro-latest`, and `openrouter/free` are listed.
